# 随快照保存的运行库

`DeepInfer/ascend910c/lib/libstdc++.so.6` 是验收环境中未修改的 GNU C++ 运行库，二进制校验值见 `../SOURCE.json` 与快照的 `ascend910c/runtime.json`。本目录保留 GNU GPL v3 与 GCC Runtime Library Exception v3.1 文本，来源分别为 GCC 官方镜像 `COPYING3`、`COPYING.RUNTIME`。GNU libstdc++ 源码入口为 https://gcc.gnu.org/git/ 与 https://gcc.gnu.org/onlinedocs/libstdc++/ 。其它组件沿用各自原有许可证。
