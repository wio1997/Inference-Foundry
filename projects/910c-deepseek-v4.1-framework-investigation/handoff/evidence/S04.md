# S04：Engram从输入、历史到两处消费

2026-11-08，首轮价值判断/条件完成。先由实际消费者形成以下工作组，再匹配历史；没有新增NPU测量。范围包括准备阶段及层1/14的Engram消费，避免只看准备而漏掉跨层/跨迭代机会。

## 实际路径与汇合

runner `_model_forward` → `DeepseekV41Model.prepare_engram_inputs:1392–1488` → `prepare_engram:1098–1240`。固定multistream overlap=False，准备同步执行。共享CPU-UVA表使每表dp_size=1，不走每步DP hash gather/row exchange；TP8仍按head分片，每rank有3/24个head。

真实非空请求：dead/有效token mask → INT32 request-index → 映射token写入slot history → 两层hash一次launch → 各层本地head的UVA gather/dequant → TP head allgather → `[T,6144]`固定bank/copy/尾部清零 → ready发布。hash先按当前chunk，再known lookback，再已提交slot history取来源；sticky blocked影响后续ngram。空token直接返回；idle DP无请求不hash，共享表可以退出lookup，但仍写无效mask/输出bank并发布事件。

模型入口SP切分mask/IDs/hidden；层1、14分别等对应bank ready，再将lookup按token轴SP切分给该层。`AscendEngram.forward:34–57`：

`KV = BF16Linear(E[6144], W[6144,25600])`，分成四路key和一路value；
`Xo = FP32(X) · Rᵀ`；
`d_c = Σ_h(Xo_ch · (q_ch·k_ch) · K_ch) / (sqrt(mean(Xo_c²)+eps) sqrt(mean(K_c²)+eps) sqrt(H))`；
`g_c = sigmoid(sign(d_c) sqrt(max(abs(d_c),1e-6)))`，无效mask时g=0；
`Y = BF16(FP32(X) + g·FP32(V))`。

固定A3 Quarot走rotated分支，不套用unrotated专用kernel。原始保存module_identity已核实两层均`AscendUnquantizedLinearMethod`、BF16；W8A8标签不代表该层INT8。下一Attention/mHC读取更新后的Y，不能把更新前aux/隐藏状态当成同值；两层表、hash参数、WKV和通道权重各自不同。

## 由最终需要反推可消失的工作

**hash/history共同部分。** 请求归属已只生成一次跨两层复用；两层当前chunk/lookback/blocked来源决策相同，但rolling乘子、prime和offset不同，不能共享最终rolling数值。可以共同解析来源、合并request-index与history双输出，或只产生本rank实际读取的3个head hash而非24个；必须保留完全相同的整数运算、所有当前读者和history写入。当前hash已单launch覆盖两层，不能再次认领合并launch。写history与后续fallback可能指向同slot，不能用跨CTA无屏障的“writer+hash一核”替代完整提交边界。源码还记录原request-search直接塞入hash的编译失败；这不排除不同双输出算法。

**lookup→SP所有者。** 下游每rank只要T/8行的全部24head。当前先让每rank得到T行全部head，再丢7/8行；可将head→token所有者转置为AllToAll，精确复制同一BF16值。T24每层逻辑off-rank接收258,048→32,256B；T6528为70,189,056→8,773,632B。输出bank布局/稳定地址、head顺序、无效ID零值及layer1/14分别ready必须保持。lookup已全写正T的local head，预清零有删除空间；空/部分head分支保留。两层能打包只额外省一次提交，且层14的准备不能拖晚层1。所有这些属于同一交付预算。

**WKV布局和跨迭代结果。** 原每rank每层全权重314,572,800B，小M3只471,859,200 MAC；改变分片会减少重复权重读取，即使MAC不变也可能快。K方向分片后做FP32 partial reduce-scatter需要2,457,600B/rank，改变K归约次序；N方向分片保留每输出完整K，在更大M上计算后交换BF16列条带，避免额外K重组，但native tiling/最终rounding仍需验证。不是按权重字节就认领速度。

更大公共项是`hash tuple → E → KV → key相关统计/旋转后的系数`：这些与当前hidden无关，可跨迭代按完整内容及权重/表/布局代际缓存。hit仍要完成history、mask、状态及发布；miss协议、所有TP一致性、查表成本和容量都要算。绝不能把相同position或一个head相同当作完整tuple命中。

**gate公式与融合。** q·k、rotation.float可按权重代际预计算；hidden widening可供rotation和残差共用。square、weighted dot、key norm可合并读取/归约，六个FP32中间plane可不落地。WKV的BF16边界、FP32 rotation/归约及最终乘加精度仍需保持。实数上可把rotation从hidden移到key相关系数，并在正交条件下化简norm；有限精度下需验证矩阵性质与模型误差，不能因实数恒等就跳过现有rounding。单独gate价值低，不为这条另开深挖。

无效mask使key/rotation/dot成为死工作，但原`0 * V`在NaN时不等于简单透传hidden；不能删value及IEEE传播。按真实活跃分布分裂K/V才可能省projection，需扣重复权重读、分裂调用与行整理；不能从padding形状推活跃率。

## 整段价值判断

估价原件与复算见`engram-entry-value.json`、`tools/price_engram_entry.py`，不读旧候选表；以下基线分开使用。

1. **单独交付/zero/transpose/owner交换：C8低值整组停止。** 相符历史跨rank时钟约束敏感性即给named delivery全免费，TTFT最多5.801ms（0.389%），整批132.000ms（0.710%）。这涵盖该交付范围内的逐对融合/搬运替代；不能再用allgather长跨度给第二份收益。T24同次allgather有rank不到9µs完成，而另rank跨度2–7ms；后者混有输入ready等待。大prefill有独立消息成本，已在上述全负载估价中计入。新的共同producer若消去额外等待/host工作，须单独证明新增工作量。
2. **单独gate/常量/中间plane：C8低值整组停止。** 当前同一caller周期完整gate最多0.604%，加direct lookup最多0.743%；旧C8 vector全免费敏感性也仅0.383%整批/0.454%TTFT。已有synthetic native常量+cast复用bit-exact，约154.50→145.41µs，只证明该机制，不升格为服务收益。所有同范围局部子方案一次排除。
3. **单独WKV分片/加速：当前周期优先级不足，不实现。** 相同当前profile，整个WKV占周期0.793%–1.037%，到1%需删原WKV的96.4%–126.1%，还未计替代projection与通信。不能因每层300MiB就深挖N/K分片。长提示WKV中位约2.48–2.63ms/两层/对应body，低于1%的body尺度；涉及更多输入等待的联合方案转下一项，不共用此排除预算。
4. **C06：跨输入发布、交付与Engram内容结果复用，留条件。** 当前同条件已保存的cacheable work约0.697575ms/周期，常量约0.02682ms；要求71.1%–96.3%的旧可缓存工作消失才到该profile周期1%，中位75.4%，且这个门槛尚给常量免费。真实条件是`hit加权省时 - 查cache/miss协调/发布/额外内存代价`超过同基线1%目标。新旧周期/旧18.59s端点不混用。完整tuple命中率和净cache/miss成本是会改变取舍的参数，先登记继续；位置重叠不是命中率。
5. **已有两个相符扩大准备方案不重复。** 原同步→辅助stream的同scope C8为`SERVICE_GAIN_NOT_ESTABLISHED`（对各自pre/post为+0.718%/-1.077%），不重做同flag。真实worker staged prefix更换方案native净host中位DP0/1为0.374/0.339ms，未达其0.558ms优先级门槛，停止该原样变体。与C06有交集，不能给prefix另加一份预算；新的内容命中机制不由原变体失败直接排除。

C06只保留具名条件，不是已发现可兑现的1%收益。上述历史机制本身不是本轮首次发现；本轮由代码消费者形成工作范围后相遇复用。继续沿目标hidden→第0层，不把Engram历史控制分支数当覆盖分母。
