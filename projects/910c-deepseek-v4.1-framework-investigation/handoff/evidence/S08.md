## 主路径、分支与汇合

`DeepseekV41DecoderLayer.forward`的FFN HcPre → `RmsNormCast`双输出 → `DeepseekV41MoE.forward:262–330` → 内部FP32 gate → `AscendRoutedExperts.forward_impl:693–795` prepare/TopK → W8A8 adapter → `moe_comm_method.fused_experts:555–623` → 自有`dispatch_ffn_combine`（DFC/F21） → finalize裁回SP原行 → shared/routed tuple → `muls_add_triton` → FFN HcPost → 下一层。

固定TP8/EP16，384专家、每token K6、每rank24专家、intermediate2304、clamp10、routed scale1.5；shared1且权重复制、SP本地计算。`already_sequence_parallel=True`使MoE不再额外shard/gather；prepare只对齐DP需要的本地mask/后缀，finalize裁回原SP行。固定`enable_fused_mc2=1`、A3 rollback使`use_mega_moe=False`，实际是自有DFC；ALLGATHER、普通All2All、CANN MegaMoe、LoRA、EPLB/force-load-balance、mix-placement不在正式负载路径。profile/capture的force-balance不是正式dummy推理分支。

当前`num_hash_layers=0`，仍为sqrtsoftplus动态路由。保存当前4480次target gate的typed table均不存在，不套用只算固定6个expert logit的hash表方案。具体bias_vl/ID适配由runtime对象决定；原profile有typed ID包，纯文本不等于代码不经过这些转换。

shared overlap配置False，shared MLP在routed完成后由当前stream执行，形态DQ→Gate/Up→clamp SwiGLU/quant→Down；结果与routed分支汇合。不能将已经存在的prepare milestones或False分支中的事件当作正在重叠的计算。

## 从最终输出倒推数学和可删工作

本token需要`shared(x) + 1.5 Σ_{e∈TopK} p_e expert_e(x)`及原BF16/FP32舍入边界。路由选中结果由`sqrt(softplus(logit)) + correction bias`等原规则决定，输出权重取对应未加选择bias的score再归一化。非零bias会破坏直接对原logit排序的等价性；即便排序可借单调性简化，6个权重的sqrtsoftplus及归一化仍需算，原有限精度/TopK tie、tiny clamp和sentinel语义保留。不同专家权重不同，不能因输入相同就省6份线性变换；shared权重也不等同任何routed专家。

RmsNormCast双输出有真实不同读者：BF16给expert、FP32给router。不能未经精度证明用BF16再widen取代FP32原值，或把gamma/rstd折权重后取消原中间rounding。可共同生产norm、router与expert量化包，TopK epilogue避免logits落地/提交；不把仍需全384维的动态gate GEMM当作被消除。

DFC已是megakernel。原C++一调用涵盖routing quant/sort、EP输入发布、GMM1、已融合的dequant/clamp/SwiGLU/absmax/requant、GMM2、return、unpermute/加权归约和跨rank协议。`dispatch_ffn_combine_kernel.hpp:244–259`按**物理M×K≤4096**选CombineV2，否则V1；小decode及大prefill/混合各保留，不能用实际有效行替代padded物理M来判分支。

在内部，GMM1的4608个FP16值仍是量化/通道缩放后的必要边界；18个N256列块的gate/up要配对，2304宽absmax完整后才能量化。INT8激活随后有20个GMM2输出列块读，FP32 activation scale还要供GMM2 dequant/combine。可以减少内部GM交接，但“一个core承接activation”不能消掉其它列块的读；网络返回及route加权也不能因为GMM2完成而消失。把route权重提前乘进quantized activation改变amax/rounding与归约次序，不作免费数学移项。

跨层有相同ID/sentinel适配结果可按typed token代际共用；激活、路由score/权重和专家权重每层不同，不跨层共用数值。Post→下一Pre的rounding/迟到残差、Engram/aux读者由S06覆盖；MoE末尾融合必须保持`routed×1.5+shared`原舍入，不能用代数分配律直接绕过BF16中间值。

**router小包/TopK-only整组排除；C12只留主计算联合条件。** 形成共同router工作后匹配`CLEAN-ROUTER-STAGE-VALUE.json`：target ID包+gating全部免费最高0.721%同周期；连同shared RMS单独边界也不足1%。整个router+RMS约1.88%中位周期，若要1%需净删约53%（不同window各自分母），必须改变gate GEMM/共同producer的主工作并扣替代代价，不再为单独Cast、TopK或logits小plane深挖。固定表不存在使selected-dot分支无净可删工作。
