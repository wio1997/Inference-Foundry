# 稳定前缀共享：受限原语的边界论证

介绍：给定不可变tokenizer代次及一个已知prefix，复用该prefix的ID tuple，再计算suffix并交付每请求新list。此契约不含在线prefix发现/LRU，也不含MM/embeds/pair/pretokenized输入或其它分词器。固定JSON c90dfa01…、binary fa049ce9…、BPE dropoutNone，normalizer是空Sequence；完整预分词第一步是数字\p{N}{1,3} Isolated，后续固定Split及无add_prefix_space的ByteLevel，postprocessor是只处理offset的ByteLevel。

到了哪里：选择prefix末尾恰为三位ASCII数字，前一字符不存在或为ASCII非数字，并排除prefix任何后缀是任一AddedToken的proper prefix。固定added token的lstrip/rstrip/single_word全False，normalizer恒等，因此任一literal added token都不会随未来suffix改变跨cut识别；完整token若也是更长token前缀也由proper-prefix检查排除。数字段第一步Isolated在该cut形成稳定piece边界：suffix即使以更多数字开始，也从下一组三位开始；后续预分词只继续拆分、不能合并已隔离pieces。ByteLevel不自动加空格，BPE以piece为域且无dropout，故prefix/suffix各piece的ID结果串联，等于整体encode_batch的ID序列。固定postprocessor不增IDs，add_special_tokens当前两种值对ID串不插入BOS/EOS。右侧cap截断在串联后做，与原整体截断同序；其它truncation/offset/special配置必须回退，不能从该定理外推。

原语先对完整text做UTF8可表示性检查，失败回到原整体API，保留错误类型/位置/后续状态；非str、prefix不匹配/不安全也原路径。输出从immutable tuple创建独立list，不让请求写回共享cache。cache必须按实际tokenizer/vocab/normalizer/flags代次失效，不能只用id(tokenizer)或文字prefix作跨模型key。

冷miss无需再encode prefix：原HF BatchEncoding保留native encodings（即使没有要求返回offset_mapping），从完整Encoding的字符token_to_chars做二分，验证前一token恰在cut结束、后一token不跨cut，再从已有IDs提取prefix tuple。该数据交付在BaseRenderer._build_tokens_prompt丢弃Encoding之前接入。若cap使prefix未完整出现则不插入；不能用UTF8字节长当字符offset。实际prefix117067字符但117187 UTF8字节，错误bytecut控制被拒绝。

结果：native1256 cases/269698 ID elements零差异，24fallback含不安全cut、无匹配和非法UTF8等；8份真实输入重建/cap1/17/33793、Unicode/数字/特殊token多例以及输出list mutation控制通过。另8个原Encoding提取均等于独立prefix原语，31次增量插入中位.182108ms；有限测试不是全序列证明的替代。任意commonprefix拼接已由实际BPE反例排除。

实际服务分派另见actual-tokenizer-dispatch-frontier.json：DeepseekV41Tokenizer只覆写chat及属性，scalar encode/decode继承HF；renderer为DeepseekV4Renderer→BaseRenderer，没有HfRenderer自动pool。原语只有在真实backend指纹/配置守卫成立时才可启用，完整bootstrap/服务wire和在线policy未准入。此证明不声称不同normalizer、AddedToken strip/singleword、ByteLevel加空格、任意BPE随机性/其它postprocessor或Fastokens分支等价。
