# 词嵌入实际派发、首层静态计算与输入交付

介绍：独立沿当前 V1 `_preprocess`、模型构造/注册、量化描述、FULL 捕获入口，追到 target 首层 Q/KV 及 DSpark query/context 的实际消费者，再与旧范围和原 C8 数据相交。每个替换原语必须逐位一致；BF16 末位差异即失败。尚不能保证找全融合机会。

到了哪里：23 份当前 Python 源身份、1 份此前精确 SHA 的 HF 类；29 个原方法/谓词的受限 stdlib 控制通过。新绑定 7 处，原 156 处静态控制位现 77 已绑定、79 仍待追。它们不是算子数、执行人口、递归调用图或全链路覆盖率。源码控制不导入 Torch，不证明实际加载对象、NPU 位一致或事件安全。

结果：更大的输入 frame/Engram/图入口交付保留深入；首层静态预计算独立保留具体缺口；旧 lookup/copy 同预算小方案不重开。本轮原语准入 0、框架替换准入 0，已有封闭 CPU 租约原型 1 的资格不变。

## 待确认：输入 frame、Engram 准备与图入口交付

介绍：边界包括外部 embedding、持久输入 bank、必要坐标和 metadata 就绪、Engram producer、目标/草稿首层 HC/QKV；可以改 layout、公共字段、发布顺序和等待位置，不能把整段窗口全当成静态 cache 收益。

到了哪里：原 HF 类展平 vision 32 并明确设 `is_mm_prefix_lm=True`；当前 converter 对 deepseek_v41 使用 base，保留该值。保存 serve 未关闭 MM，支持 image 的默认上限为 999。纯文本也进入父类 MM embedding 预处理。实际 worker 注册共享 OOT registry 后，构造的是 Ascend embedding，默认 STANDARD TP8。当前 8,677,636B 量化描述的 target/draft embedding 为 FLOAT，经前缀映射和 helper 选择原 F.embedding，再作标准 TP AllReduce；Engram 的 INT8 表是另一条路径。没有读取权重 Tensor。

普通 eager 向 target 传入外部 embeddings，模型不再查表；FULL 的原 `_dummy_run` 因 `requires_raw_input_tokens=True` 捕获 raw IDs + `inputs_embeds=None`，replay 执行内部查表。原 profile 对应 FULL 有内外两次 lookup，eager 只有外部。运行时调用参数不能改写已经捕获的图体。DSpark 的 MM 预处理按 draft embedding 签名关闭，自身 query 只查一次；target/draft 描述均为 FLOAT 不代表两套权重相同。

Engram producer 的输入是原 IDs/positions/lookback/QSL/物理 slot/table；先发布 keep-mask，再 hash、公共 gather、两层查表和各自事件。SP 在模型入口等 mask 后复制它，lookup 在层 1/14 就绪后分别分片。可探索把 mask 的 wait/分片延后到首实际 Engram consumer，让首层与生产重叠；必须保留 FULL ExternalEvent wait/reset、DP/TP 次序、异常/跳过 consumer 的 join、输入 lease 和上一轮 bank 末读。现有 slotless capture helper 明确排除 SP，不能直接开 flag；这不证明新的 producer graph/megakernel 不可实现。

结果：**待确认且值得深入**。已有原 C8 3696 个完整 rank 窗中，本 reader 价格覆盖 3624 个有实际请求的 rank 窗、453 个 TP8 组、227 个活跃波。更大的 target+draft 输入到首 SMLA/更早 HCPost 全免窗口为 TTFT 35.159340ms（2.356753%）、整批 940.385085ms（5.058344%）；TP8 局部乐观窗口中位 3.600180ms。包含必要 host/Engram/graph-entry 工作和等待，不能全删，也不是新速度测量。

在同一保存时钟/固定调度 replay 内，假设可删且能暴露比例 25%、每波新增 0.1ms，TTFT/整批条件净省 8.289835/212.396271ms（0.555673%/1.142482%）；比例 50% 为 17.079670/447.492543ms（1.144861%/2.407068%）。未知比例默认 0。单纯挪 wait 是否移动请求关键路径、producer 最早释放/末读、争用及新增发布成本仍缺，不能把两种敏感性相加。

人口限制：原数据在 227 活跃波实际存在 454 个物理 DP 组；其中 1 个 synthetic、无实际请求组的 8 rank 窗未在本 reader 价格中归因。与并发 token 账本的 3632 物理 rank 窗口径不同，不能称完整物理组上界。旧诊断 311.050ms self-Free 属于另一 cohort/窗口，也不能与本段相加。六普通负载的新整段价尚缺。

## 待确认：首层静态数学、热行 cache 与布局

介绍：从固定 embedding/四路初始 HC/pre_mix，到首层 HC 系数、归一化和 pre-RoPE Q/KV，先问能否按词、shape/lane/rank/backend/权重代次预计算或共享，范围大于 lookup/copy。第 0 层无 Engram、压缩或 indexer，位置/历史依赖在后续 RoPE/cache/attention 才进入。

到了哪里：用同一旧数据库进一步提取 3624/3624 资格通过的 Qb、512 维 KV RmsNorm 末端。空 query 以 KVnorm 结束，不再把晚到的动态 Oproj/HCPost 等待算成静态可省。target SP 在 HC repeat 前，draft repeat 在 SP 前；原残差、系数、mask/tail、各原语舍入与后续 HCPost 读者都保留。仅数学位置无关不足以证明 native 每行位一致；已有 changed-M/AGMM 位差反例不能忽略。

结果：**待确认，暂不开发全词表缓存**。首 HC→Qb/KVnorm 的 target+draft 全免预算在当前活跃请求人口为 TTFT 0.710251%、整批 0.456940%，局部 TP8 中位 0.322000ms。50% 可删且暴露、每波新增 0.1ms，条件净价只有 0.321610%/0.106367%；25% 时整批已为负。成本比例不是实测。

同一固定 replay 的保守包络可用“旧具名 lookup/SP/outer-bank endpoint credit + 新数学段最大单请求 credit”给出：TTFT 16.552565ms/1.109529%，整批 178.064188ms/0.957810%。依据 `max(base-named-math)>=max(base-named)-max(math)`；两段预算不重叠。此包络仅覆盖已定读者/调度/活跃请求人口，不能用作改变 attention、物理资源、全部 padding 或更大输入交付的停止证明。

具体缺口：六普通负载整段曝光、synthetic 组关联、精确 shape/lane/rank keyed native 位、热行人口与容量/维护成本。全词表 Q 为 129280×32768×2=8,472,494,080B/副本（纯代数），尚不含 HC 状态/KV/cache key；这不代表当前可用内存或实际分配。优先复用旧数据定价热行子域，只补会改变去留的参数。不能借旧 lookup-only 低预算剪掉这个更大数学 parent，也不能因该 parent 弱而剪掉上面的输入/Engram frame。

## 待确认：DSpark 公共扩展与每物理组地址交付

介绍：从 target global QSL/seq、下一 token/rejected 数和各组 block/slot，沿原 Triton 扩展到 query/context bank、三 draft 层和五步 Markov。

到了哪里：setter 存的是 Tensor alias。kernel 的公共 IDs、context/query positions 和 sample indices 没有物理组依赖；context slot copy、query slot 则依赖物理输入、block size/table/stride/DCP。5 query 是 q0 的 anchor + q1..4 的 noise。普通实际请求 B1/B2/B3 也观察到 embedding 行 10/15/20，可能含 metadata dummy 请求，不能把 shape 直接当 5×实际请求。三个 draft body 合并运行一次，之后是 K 步 Markov，不是 K 次重复三个 body。

扩展之后 `cad.query_start_loc`、seq、CPU mirror 和 slot 重新绑定；属性赋值不覆写旧 QSL 的 Tensor storage。异步 kernel 仍可读旧地址。runner 的 26 CP caller 包含 cache 资源组，不能称 26 个 target-only 资源；draft 组按 KV group 与 backend/spec 交集构造，真实分组人口仍需匹配。

结果：**待确认**。公共字段只生成一次 + 分组物理 mapping/megakernel 有合法源级切分依据；真实组数/顺序、所有 final reader、最早 storage 写、完整整数/tail/错误输出与匹配净价仍缺，没有为“重复几次”提前记收益。原首次 global QSL H2D 已有中间 slot/logits 读者，仍不能删除。

## 已确认可实现、已停止和下一段

已确认可实现：本轮 0。29 个源码控制通过仅确认受限 source contract。历史封闭不可变 CPU 租约原型 1 保留，未晋升为服务框架/NPU 替换。

已停止：旧具名 lookup/copy/SP-only 全免预算原 C8 TTFT 0.39928%、整批 0.50087%、六普通最大约 0.61972% 的同预算独立小方案保持停止；仅配置澄清不重开。拒绝“纯文本意味着没有 MM 预处理”“runtime embeds 意味 FULL 内部 lookup 已跳过”“五 query 全为常量”“cad 重绑意味着旧输入已退休”“忽略 packet padding”“BF16 尾位容差放行”等具体配方。停止这些推论不停止更大 parent。

下一段：继续 79 位及递归 helper 的实际输入/组构造/consumer，优先补大 frame 的 source 就绪、producer_done/consumer_done 与首次覆写；走 Engram slot-cache hash、物理映射、DSpark common→per-group 最后读者和错误/空 DP/FULL 分支。原始 18 root/295 callsite 不是完整调用图。无已确认 live 任务等待；新 Torch/NPU/模型/profile/请求/服务动作及远端写入均为 0。
