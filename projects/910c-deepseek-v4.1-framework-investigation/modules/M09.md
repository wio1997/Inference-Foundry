# M09 采样、校验与输出状态

执行位置：target logits 到已接受输出及后继状态。当前记录状态：`SCOPED_PRIORITY_DISPOSITIONS_RECORDED`。完整模块优化穷尽：**未证实**。

目标词表投影后的选词在两组 TP8 中实际执行 453 次，428 次为 24 行（4 个 bonus、20 个待校验行）。保持原有全词表收集，融合转置、选行、类型转换和 ArgMax，C8 整批估算省 31.11–32.64 ms。若各分片保留同分时的全局 token ID，只交换局部分数和 ID，一次小包交换时整批约省 27.48–47.78 ms。依赖原有状态而需两次交换时约省 8.96–41.46 ms。两种通信成本取自本机历史小包校准，完整分数、额外读者和随机采样分支另需合同。 [逐形状、通信和读者](../baselines/vocab-selection-fusion.json)

目标与草稿两处都融合时，按一次小包交换，18.591 秒的 C8 整批估算省 56.07–77.12 ms（0.30%–0.42%），首 token P90 省 0.55–1.06 ms。按两次交换，整批省 37.57–70.82 ms。六个普通请求用实际校验次数计价，一次交换时单请求响应的估算降幅最高约 0.15%，一行 prompt 仅有一个匹配样本。在冻结调用次数和投影成本的宽松筛查里，按每轮目标和草稿各自最耗时的 rank，把两个投影后区间除五次 W2 外全部免去，整批也只省 179.92 ms（0.97%）。本组退出独立深查。 [联合请求估算](../baselines/vocab-selection-fusion.json)
