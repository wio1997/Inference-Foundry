## 实际分支与排查范围

SWA/稀疏 attention、索引源层、QLI/MLA、KV 发布、prefill/decode、rank 无本地 attention 但参与通信。

## 已有价值判断

当前 QA+index-W 完整小区间至多 0.424%，重复 QR 量化至多 0.040%；SWA 直接 join 乐观筛查最高 0.882%。大输入 OA/打包/通信按匹配频次计价也暂缓独立实验。

## 必须保留的语义与读者

保留 RoPE/量化边界、KV 和索引缓存读者、候选与长度、row ownership、TP 参与者。缺失 SMLA 记录不意味着该 rank 可删除。

## 融合之外的完整改写空间

QLI 到 MLA 的 selected-KV 交付；SMLA tile 重组；生产端布局/通信；RoPE/store 联合；跨层缓存和状态发布。

一个值得继续查实际收益的设计，是让第 24、28、32、36 层共享一次 QLI 候选集合转换。归档中自然的四请求、每请求调度六 token 的步骤在 DP0/DP1 分别有 213 和 215 次。若只在这些步骤生效且收益沿原请求累积，每个命中步骤需要实际提前 0.873 ms。相关单卡构造用例已把转换计入，四个消费者合计净省 1.264 ms。若每步都命中，至少要把这项参照的 69.1% 兑现到请求上。此前修正版服务耗时落在前后参照之间。本轮模型内计时已覆盖实际四个消费者与后续 TP 交换。 [命中范围与端到端盈亏平衡](../baselines/c8-endpoint-screen.json)

原目标图的 16 个 rank 各有 227 次回放。按 TP8 通信调用编号对齐，第 24、28、32、36 层的 QLI 都出现在 DP0 的 213 个、DP1 的 215 个自然满批步骤。在四层局部缩短都能传到下游打包完成的假设下，无论哪张卡最后到达，每步骤四层合计的估价差最多 32.44 µs。扣除另一次单卡用例中一次转换加四个替代消费者的代价，要达到整批 1%，这份预算需要有 68.1%–69.1% 在实际请求上兑现。原服务对照每组一次，八份文本一致，但各组的分 DP 前缀命中数、草稿提出与接受 token 数存在差异。这项估计用于选定下方模型内对照的测量范围。 [按步骤与实际 TP8 调用对齐](../baselines/qli-request-frontiers.json)
