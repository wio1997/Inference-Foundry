# 本目录的任务范围

本目录承接用户明确指定的 171 全模型算子优化排查与持续报告任务，独立于分支根部旧的 172 DeepInfer 部署任务。旧部署授权、PID、服务状态和性能数字不能作为本目录的实时事实。

先读 README.md、progress.json、REPORT.md 和当前模块文档。按模型执行顺序推进，先判断完整可变工作及频次的价值，优先已有 profile，仅为会改变结论的缺口定点查代码或补实验。

每个实质进展同步更新模块、总报告、进度、追加日志和证据索引，并提交 Git。保留失败与纠错记录；不把报告成稿、索引无缺项或局部正确性通过当成整体完成。不得上传凭证、模型权重、完整 profiler 二进制或编译缓存。

服务器数据仍只放在 /data/tiankuan/wio。当前目录的文档操作不授权操作同分支的其他项目服务。

融合筛查从具体算子和消费者出发，先说明同一布局、路由与权重分布下可以消掉的中间读写、计算或提交。冷热专家与副本分配只保留历史记录。将同一机制跨层和跨迭代汇总到请求时间，普通场景也达不到收益门槛时登记停止理由。缺失分支的依赖标为待定。

跨模块和分支融合可以由共同输入、共同读者、直接生产消费或可合并的同类提交成立。独立改动同时启用时的请求收益保存在组合估算中，每条融合候选仍需指出自身能消除的工作。
