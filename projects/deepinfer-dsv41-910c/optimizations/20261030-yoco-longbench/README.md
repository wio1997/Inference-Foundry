# YOCO 有界重放的长文配对检查

测试时间：2026 年 10 月 30 日。该检查比较当前 DeepInfer 910C 适配的精确路径、140 token 和 256 token 有界重放；不改变保留服务源码。测试使用七个独立问题，不能作为完整 LongBench v2 分数或三种路径普遍等价的证明。

## 方法

- 数据：官方 [LongBench v2](https://huggingface.co/datasets/zai-org/LongBench-v2) 的原始文件，503 条，SHA256 `15d61c22d92c96900b3c4948b6aeea218d3214b676a65df48e7b8555604c7fe2`。从字符数 40,000–300,000、编码后长度 29,569–32,768 token 的样本中，按固定 ID 哈希顺序选取七题；包括单文档、多文档和长对话三类。
- 提示：使用 [DeepSeek V4.1 Flash 1017 官方编码器](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/blob/main/encoding/encoding.py) 的 `chat` 模式，以及 LongBench v2 的零样本问题格式。编码器副本 SHA256 `13231c592e958fb39e2af6001dae69d90e7a36b265702b9b390236fb387599e2`。
- 输入：保留完整文档；在文档末尾加入空白，使输入满足当前 YOCO 的 128 token 对齐条件。七题分别增加 35–122 token；每题的三种模式使用完全相同的输入。对齐后输入为 30,336–32,640 token。
- 部署：172，W8A8，16 个逻辑设备，DP2×TP8/EP16；每题以八个相同请求并发执行。每个请求实际命中 29,568 token，命中率约 90.6%–97.5%。逐模式重置并重新建立相同前缀，核验 16 rank 的模式、实际路径与缓存数据。
- 生成：贪心、`ignore_eos=true`、每请求输出 128 token，与既有 YOCO 适用条件一致。按首个 EOS 前的文本使用 LongBench v2 原有答案提取规则评分；同时比较包含 EOS 后内容的完整 128 token。每题的八个副本属于同一个问题，不计作八个独立样本。

当前服务只有在 `ignore_eos=true`、末尾对齐等条件满足时才执行此有界重放。此前正常 EOS 的试运行虽然命中了缓存，但实际回退到精确路径，不作为 140 路径结果。未对齐及未使用聊天格式的试运行均保留在服务器，不纳入本次统计。

## 结果

| 路径 | 七题答对 | 七题答错 | 未解析或副本答案不一致 |
| --- | ---: | ---: | ---: |
| 精确 | 5 | 2 | 0 |
| 140 token | 5 | 2 | 0 |
| 256 token | 5 | 2 | 0 |

三条路径在七题中给出的答案逐题相同。各模式间按相同 DP 和槽位比较，首个 EOS 前的 token 序列及 EOS 位置均为 56/56 一致；各模式两两之间，完整 128 token 序列均为 20/56 一致。未完全一致的部分位于 EOS 后，而本次请求设置仍要求继续生成，因此完整差异也应保留。

七题及其并发副本、不同命中率和人为添加的空白均限制结论。此前自定义长前缀算术样本曾出现有界重放与精确路径的 EOS 前差异；这两组证据不相互替代。当前结果不能证明 140 或 256 与精确路径的缓存语义、模型质量或其他负载完全一致，也不测量性能。

21 组诊断执行约 169 秒。服务器原始数据与各 rank 证明位于 `/data/tiankuan/wio/910c-deepinfer-172/diagnostics/longbench-v2-paired-v3-20261030/`；独立审核文件为 `/data/tiankuan/wio/910c-deepinfer-172/evidence/longbench-v2-paired-v3-audit-20261030.json`，SHA256 `3afda11ca90cd401b96c6c257b4066ccb6617811a47365e8c6489b5f9734c7d9`。样本与种子 ID 冻结文件 SHA256 `450e74b470b984208afdeee6dd9edba5991ba70c692d1b339a11dd8c2bfeb961`。测试后保留服务已核验健康、16 rank 和原有开关。
