# DSpark 输出事件合并写入验证

## 目的与实现

此前的单次逐 rank 诊断显示，两个 DP 的主进程经常最后进入状态投票；这只是相关现象，不能证明输出写入是瓶颈。候选在独立副本中将同一请求、一次 DSpark `output()` 产生的多条 token 与结束事件按原顺序合并为一次行缓冲文件写入。缺省关闭时沿用原来的逐事件写入；首 token 是单条输出，不等待后续 decode。候选不改动模型计算、投票、DSpark、Engram 或缓存规则。

批内事件会在该次输出结束时一起对外可见，因而可能改变客户端观察到的流式时序；时间戳也可能发生微小变化。输出内容和顺序的一致性不能单独证明流式延迟无退化。

## 正确性

本机模拟覆盖 96 组输出序列、EOS 和长度结束，文件跟读覆盖首 token、多个 slot、完成事件和结束后的重复输出。单次真实 SSE 检查对 8 条 32K 输入分别以两种 EOS 设置开关候选，共 32 条请求；token、文本、结束原因与缓存命中一致，16 rank 路径核验通过。该组没有触发 EOS，审计 SHA256 `d036a47dac7cec00a8433d500091c81d4b0380235a2656fb3fd87f47fd8edd8e`。

补充使用历史 8 条 32K 长输入，分别关闭和开启候选，实际均有 6 条请求因 EOS 提前结束；两组的 token、文本和结束原因一致，缓存命中均为 8 × 29,568。该选定样本覆盖了真实 EOS，不代表所有输入和调度状态。审计 SHA256 `7490d431b6fbff9b7835d544354c96726fa6df9a8b9b1a2c02acad2875db5f14`。

## 同服务性能对照

172，W8A8，16 个逻辑设备、DP2×TP8/EP16；32,768 输入、1,024 输出、并发 8，实际 KV 命中每轮均为 235,904 / 262,144。按关闭、开启、开启、关闭顺序执行，各配置两轮；其余已接受优化及配置相同。

| 候选 | 轮次 | TTFT（ms） | TPOT（ms） | 输出吞吐（token/s） | 输出事件 / 批写次数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 关闭 | 1 | 586.1 | 12.3 | 614.278 | 8,200 / 逐条 |
| 开启 | 1 | 590.5 | 12.3 | 613.666 | 8,200 / 1,762 |
| 开启 | 2 | 601.2 | 12.2 | 608.869 | 8,200 / 1,752 |
| 关闭 | 2 | 595.9 | 12.2 | 609.511 | 8,200 / 逐条 |

四轮各 8 条完整 1,024 token 与固定参考逐 token 一致，均核验 16 rank 的既有路径和实际缓存。开启后两轮写调用明显减少，但 TTFT 分别高 4.4 / 5.3 ms，吞吐分别低约 0.10% / 0.11%，TPOT 持平。两轮、单次同服务 ABBA 不能将细小差异归因于候选，也没有证明稳定收益；按保留优势和不掩盖退化的约束，**不采纳候选**。

## 客户端流式间隔

对 AISBench 保存的客户端 SSE 数据块接收时间点计算相邻间隔，包含最后完成数据块；数据块可能为空或不与 token 一一对应，因此不是设备 token 延迟。按表中顺序，四轮的间隔 P99 为 57.046、57.119、56.902、57.505 ms；单轮最大间隔分别为 65.589、61.101、71.123、62.019 ms。开启第二轮的最大间隔更长，但样本和时序不足以确定原因，不用该值单独判定普遍退化或收益。

## 证据与限制

正式对照独立审计 SHA256 `bb6ad41447ddfb700a83f1061ae4debe21a47e54226f0bf1af309ffc6adcd4e4`；SSE 时间点审计 SHA256 `6e0cc4f398138e8a7165dc658336a45c4d09acc0318b3f5ff9f46114595c8725`。原始结果位于 `/data/tiankuan/wio/910c-deepinfer-172/fair-comparison-20261028/completion/zos-event-batch-ab-20261030`；两项短 SSE 审计在 `evidence/zos-event-batch-smoke-audit-20261030.json` 和 `evidence/zos-event-batch-eos-audit-20261030.json`。所有模型输入、运行日志与结果保留。

仅覆盖当前固定负载及上述少量 EOS 样本；16 rank 的设备缓存张量未逐项比较。本地锁不能排除外部客户端，同服务两轮不能证明所有负载下的效果。所用 256 token 有界重放是保留的可复现近似，不能由本实验称为与精确路径或官方 140 token 路径等价。

`event-batch.patch` 为独立候选补丁，未并入保留版本；在对应冻结源码上完成本地应用检查和四个文件 SHA 校验。回退方式为保持 `dspark_event_batch` 关闭或使用原保留版本。该候选是本地调度探索，并非宣称已经完整恢复官方 ZOS。
