# 有界重放语义与验证范围

## 官方依据

固定官方提交 `553741557a57df44a46fb3ab72b6aafeaf945337` 的 [README](https://github.com/deepseek-ai/DeepInfer/blob/553741557a57df44a46fb3ab72b6aafeaf945337/README.md) 将 V4.1 的 `compact` 示例保留长度设为 140，要求覆盖 SWA 窗口及最大回退长度。[部署说明](https://github.com/deepseek-ai/DeepInfer/blob/553741557a57df44a46fb3ab72b6aafeaf945337/doc/inference_deployment_qa.md) 将 SWA 窗口描述为 128，并说明 decoder bounded replay 对历史范围作截断、重建近似 SWA KV。140 是示例保留行数，128 是文档所述窗口及重算机制；二者不是同一个参数。

## 当前状态与已知差异

- 当前保留版本使用 256 token 页对齐有界路径；`yoco_bounded_140=false`。它保留更多行，使用不同的重算范围，属于近似路径，不能仅按保留行数宣称与官方等价。
- 910C 的独立 140 token 候选使用紧凑页重排，试图匹配官方示例的保留长度；CP 布局、索引构造、注意力内核和缓存组织仍为 910C 实现，整体语义尚待验证。
- 精确参考应关闭有界重放，明确本次请求是否命中前缀、哪些缓存恢复以及是否使用精确裁剪；不得把不同缓存状态或不同模型设置的输出混作精确参考。

此前 140 与 256 在独立候选中做过两轮 ABBA：每轮 8 条完整输出与冻结参考一致，实际 KV 命中相同；第二轮 140 的 TTFT 和吞吐不及 256。该实验使用较早组合且关闭异步草稿预发；它支持所测输入的输出一致性，不证明与当前组合完全可比，也不证明缓存状态、中间数值或模型质量在其他输入上等价。

## 后续验证

1. 使用当前已接受版本的独立候选，先确认 `yoco_bounded`、`yoco_bounded_140`、精确裁剪和其他有效优化的组合开关及实际执行。固定共同权重、分词、DSpark、生成参数与设备；记录 140、256 和无有界重放路径各自可复现的请求与缓存状态。
2. 对照官方输入准备、截断及 SWA 可见范围，核实重放起点、位置、压缩 KV、原始 SWA、采样/回退及写回语义；重点覆盖 127/128/129、139/140/141 和页边界附近长度，前缀冷、部分命中及恢复、多请求不同长度和填充。比较中间张量或 logprob 时记录精度、容差及误差分布，不假定逐位一致。
3. 在足够多且可复现的不同输入上，比较精确路径、140 与 256 的逐 token 输出、首个分歧位置和 logprob；另用适合长上下文与目标模型的有答案评测评估质量。若无法运行某类评测，应保留未验证状态，不将有限样本等同模型质量保证。
4. 在语义和质量证据允许的范围内，以固定主负载分别测量 TTFT、TPOT、吞吐及缓存命中，报告逐轮数据和退化项；相同配置多次比较时注明预热及缓存状态。任何采纳决定都应同时考虑语义、质量与综合性能，保留三条路径及回退方式。

## 部分质量诊断进展

在 Engram M24 独立候选上，使用 64 条带 32K 自定义长前缀的 GSM8K 测试样本，逐条对照精确、140 和 256 路径，每条实际命中 29,568 / 32,768 token。与精确路径相比，140 和 256 路径首个 EOS 前的 token 序列分别有 28/64 和 24/64 条不同，故不能称为逐 token 等价。仅按明确的 `Final answer: <number>` 格式提取时，精确、140、256 分别可解析 41、40、38 条，其中 36、35、34 条与参考答案匹配；未解析项不判定为答错。

上述输入带自定义长前缀，使用 `ignore_eos=true` 并截取首个 EOS 前的内容，不能作为标准 GSM8K 准确率。后续合成检索样本出现数值异常而未完成；该异常发生于独立候选，仍未确定其原因或与该修改的关系。保留版的 256 路径继续作为可复现基线，140、256 和精确路径的完整质量与缓存语义评估尚未完成。部分审计 `fair-comparison-20261028/completion/engram-m24-quality-32k-20261030/partial-gsm-audit.json`，SHA256 `ae0f9446644e433f3ab6ba18c57d419db5b688c3e34a6a0743b8f4789880fde0`。
