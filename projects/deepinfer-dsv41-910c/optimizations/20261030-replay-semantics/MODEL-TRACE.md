# YOCO 模型级 mask 与 compact 对照

日期：2026-10-30。使用 172 的独立诊断候选，与保留的 DeepInfer 910C W8A8 版本分开部署。两次运行均为 16 个逻辑设备、DP2×TP8/EP16、DSpark 和现有 Engram 路径。候选只在本次诊断中保留完整查询，并以逐索引的 eager 注意力执行 `mask` 可见范围；`compact` 使用现有 910C 有界重放与 CANN 注意力。候选未采纳。

## 测试条件

- 相同 LongBench 样本：输入 30,336 token，前缀缓存实际命中 29,568 token。各侧运行前重建相同前缀。
- 两侧均为 8 个相同请求、greedy、`ignore_eos=true`、生成 16 token，保留长度 256。所有 rank 记录的模式和执行计数经过检查。
- 两侧各保存 36 份张量，覆盖第 21、39 层每个 rank 的保留查询、索引、注意力结果和最后 128 个 SWA 缓存位置，以及两个 DP 主 rank 的隐藏状态。采样层之外没有相同粒度的记录。
- 记录张量需要同步和跨 rank 聚合；该诊断的执行耗时不能作为性能数据。

## 结果

8 个请求的 16 个输出 token 在两侧一致，每侧 8 个请求的缓存命中均为 29,568。输出相同不足以证明中间计算等价。

| 比较项 | 第 21 层 | 第 39 层 |
| --- | ---: | ---: |
| 保留查询的索引集合不一致行数 | 0 / 1,024 | 1,024 / 1,024 |
| 查询最大绝对差 | 0.0625 | 6.09375 |
| 注意力输出最大绝对差 | 0.015625 | 7.28125 |
| 隐藏状态最大绝对差 | 0.3203125 | 1,520.0 |
| 最终 token 的隐藏状态最大绝对差 | 0.0625 | 1.5 |

隐藏状态最大差位于距末尾 17–64 个 token 的范围；这是绝对差，尚未分析相对误差、数值尺度及具体通道。第 21 层的查询在进入该层注意力前已出现小幅数值差异；第 39 层的索引集合和中间结果已明显分离。两种注意力使用不同设备实现，当前证据不能将差异归因于量化误差、CP 布局、tail FFN 路径或缓存语义中的任意单一因素。

官方 `mask` 元数据和设备算子的合成输入检查见[元数据与算子对照](OFFICIAL-ALIGNMENT.md)。本次 `mask` 使用按官方元数据规则验证过的 910C 诊断实现，不是官方 NVIDIA 算子；单个样本及少量输出一致不构成完整官方对齐的证明。

## 索引源层定位

随后在相同样本上补充第 24、28、32、36 层的索引追踪，隐藏状态仍只采样第 21、39 层。各层记录的 1,024 行包含两个 DP 副本及各请求最后 128 个位置；索引集合比较忽略顺序。

| 层 | 集合完全相同行数 | 每行平均不同索引数（512 个中） | 每行不同索引数 P95 |
| --- | ---: | ---: | ---: |
| 21 | 1,024 / 1,024 | 0 | 0 |
| 24 | 20 / 1,024 | 3.55 | 7 |
| 28 | 10 / 1,024 | 4.82 | 12 |
| 32 | 0 / 1,024 | 8.35 | 18 |
| 36、39 | 0 / 1,024 | 10.19 | 21 |

第 24 层是本次追踪中第一个发生集合分叉的索引源层。先前“多数行不同”并不意味着每行 512 个索引全部不同。两侧仍同时改变查询布局与注意力实现，因此不能据此判断哪一个因素导致分叉。后续需让 `mask` 和 `compact` 使用同一种注意力计算，再检查索引是否仍然分叉。

补充证据 `evidence/yoco-mask-index-overlap-20261030.json` 的 SHA256 为 `55c71ace345dcb5b60eebc22fa7ecd986e314f47d266d29078b166c40a2c0310`；逐层位置数据 `evidence/yoco-mask-index-audit-detail-20261030.json` 的 SHA256 为 `7fcd82c572a3a09ff2aa35752d01fd0c08d19b8cedb7d50836b2de2cfbbb51e3`。复用的审计程序在限制文字中沿用了“两层”的旧描述；本次注意力实际采样六层，隐藏状态采样两层，以上述范围为准。

## 相同注意力实现的对照

隔离候选将两侧的注意力都切换为相同的逐索引 eager 实现，`mask` 保留完整查询，`compact` 保留截取后的查询；请求、缓存长度和生成设置与前述诊断一致。8 个请求各 16 个输出 token 一致。第 24 层仍有 1,020 / 1,024 行索引集合不同，每行平均不同 3.52 个；第 36 层平均不同 10.07 个。相同注意力实现没有消除该样本的分叉。两侧查询形状、CP 分区和 tail FFN 行选择仍有差异，结果不能单独归因于其中任何一项。

该实验的审计文件 `evidence/yoco-eager-audit-20261030.json` SHA256 为 `f20036733cd4bb29e3e28544c2159863766d7c4aaa676b1263c3d9a9e6fbf911`；索引集合统计 `evidence/yoco-eager-overlap-20261030.json` SHA256 为 `991fbb8f35069a74565dfc8539b3bca6376521d5a266f2564b887a9c82341fc0`。两侧的张量保存在 `diagnostics/yoco-eager-test-20261030/`。该候选仅用于定位，不用于生产性能对照。
