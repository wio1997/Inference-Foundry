# 跨子层 mHC 融合候选

## 范围

本候选参照 DeepInfer 官方 lazy mHC，在 910C 固定 24 行目标图中延迟前一子层的 post 操作，并与后一子层的 pre 操作融合。Engram 插入、DSpark 特征提取及模型输出前仍执行必要的物化。原 attention 与 FFN 归一化、DSpark、Engram CPU 表、原目标图及回退路径均保留。每个 rank 新增 218103808 字节工作区，按候选图单流顺序使用。

该候选只覆盖固定 4×6 图及指定参数，不等同完整官方实现。未覆盖的形状和非 ignore-EOS 请求使用原路径。设备 target、设备 C2 和设备 Engram 窗口未与本候选组合验证，不能同时开启。

## 测试结果

测试配置为 W8A8、16 个逻辑设备、DP2×TP8、EP16，输入 32768 token、输出 1024 token、并发 8，实际 KV 命中 235904/262144。同服务按关、开、开、关顺序测量；两组均开启异步草稿预发、256 token bounded replay 和 prefill Engram UVA，仅切换 `mhc_lazy`。

| 状态 | 轮次 | 平均 TTFT (ms) | 平均 TPOT (ms) | 输出吞吐 (token/s) |
| --- | --- | ---: | ---: | ---: |
| 关闭 | 1 | 588.6 | 12.4 | 605.397 |
| 开启 | 1 | 586.2 | 12.5 | 604.084 |
| 开启 | 2 | 609.0 | 12.4 | 596.098 |
| 关闭 | 2 | 587.4 | 12.4 | 601.016 |

合并吞吐由 603.198 降至 600.065 token/s，平均 TTFT 由 588.0 增至 597.6 ms，平均 TPOT 由 12.40 增至 12.45 ms。该负载未观察到收益，候选保持关闭；两轮样本不足以确定差异成因或稳定性。

四轮 32 条完整输出与既有参考逐 token 一致，各轮分词缓存命中 8/8。16 个 rank 在开启的两轮分别重放融合图 223、225 次，每图包含 74 个融合节点。短诊断与正式结果摘要、审核回执哈希见 `results.json`。测试不证明其他批次、EOS、设备缓存状态或通用质量。

初版真实诊断因新增图未启用 confidence 调度所需的事件计时而失败；本版本补全该接口并通过短诊断与上述完整负载测试。初版失败记录保留在服务器项目目录。

## 部署与回退

1. 以 `manifest.json` 指定的父源码快照为输入，执行 `python3 verify.py <源码目录> base`。该快照为服务器项目中的 `src/DeepInfer-official-zos-engram-window-20261029`，不可假定与其他版本相同。
2. 在独立副本执行 `patch -p1 < candidate.patch`，再执行 `python3 verify.py <源码目录> candidate`。
3. 本候选依赖服务器项目中的 `experiments/mhc-full-extension-axpy1024-build-20261029/hc_post_pre_check.so` 和 `experiments/mhc-real-tiling-24-20261029/tiling.bin`；源码使用固定绝对路径并校验两文件 SHA256，哈希见 `manifest.json`。补丁不包含上述二进制产物，也不能单独用于在其他机器重建该算子。
4. 仅在已验证配置下，通过作业配置开启 `mhc_lazy`；关闭该开关即使用原图。运行前核验设备归属、显存余量和固定镜像；不满足约束时保持关闭。

保留本候选用于复核和后续局部优化，不作为其他负载的性能保证。
