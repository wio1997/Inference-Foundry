# 正常 EOS 请求的 YOCO 有界重放候选

测试时间：2026 年 10 月 30 日。当前保留版仅在请求设置 `ignore_eos=true` 时允许有界重放；正常 EOS 请求回退精确路径。该限制是既有固定负载的适用条件，尚无证据证明正常 EOS 在 prefill 阶段必然需要回退。

## 候选范围

独立候选只修改 `deepinfer/engine/bounded_replay910c.py` 的资格判断。新增环境变量 `DEEPINFER_910C_YOCO_NORMAL_EOS=1` 时，允许四个请求均使用正常 EOS 的批次进入已有有界重放；默认关闭，混合 EOS 设置仍回退。位置、缓存、注意力、目标验证和 EOS 结束逻辑未修改，原 140／256 近似范围仍然保留。该候选不是对官方实现整体等价的声明。

基线文件 SHA256 `24dd794197b78427fe0a730e353a8e79200c6dc79189af1be64d6597751496cd`，候选文件 SHA256 `f406ff043d9b34a6a9a3a7a6f43656d80a0c588b3b226d7dd3ab56c54595f508`。复制时对 1,501 个文件做了逐项校验；CPU 资格检查覆盖 140／256、全部 EOS 布尔组合、开关关闭以及混合请求、失配和非对齐回退。独立补丁已验证可应用和反向还原。

## 测试与正确性

同一候选服务分别关闭有界重放、启用 140 和启用 256；每题轮换模式顺序。七个 [LongBench v2 配对样本](../20261030-yoco-longbench/README.md)的原文未截断，在文档末尾加入相同空白以满足既有 128 token 对齐条件。输入为 30,336–32,640 token，每条实际缓存命中 29,568 token；每题八个相同请求并发，正常 EOS，最多输出 128 token。

21 组请求的缓存命中、16 rank 路径标志及 EOS 结束规则通过独立核验。三种模式均有 56/56 个请求以 EOS 正常结束；按相同 DP 和槽位比较，三种模式的完整 token 序列及结束原因均为 56/56 一致。七个独立问题的答案均为 5 对、2 错。八个并发副本不是八个独立问题；七题不足以证明所有请求、缓存状态或模型质量等价。此前其他自定义样本存在有界与精确路径的输出差异。

正常 EOS 下，既有 DSpark 草稿预发因其原资格条件回退；这项实验没有改变该条件。混合 EOS 请求、取消、任意批次及更广泛模型质量尚未完成设备验证。
