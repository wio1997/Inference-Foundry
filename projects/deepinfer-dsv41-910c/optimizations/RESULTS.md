# DeepInfer 910C 优化逐项结果

记录日期：2026-10-30。本文汇总已完成的单项测试和已知缺口；未测量的项目不填估算收益。

## 测试口径

除另有说明，测试在 172 使用 DeepSeek-V4.1-Flash W8A8、16 个逻辑设备、DP2×TP8/EP16、AISBench 32,768 输入、1,024 输出、并发 8、greedy 和 ignore EOS；每轮实际 KV 命中 235,904 / 262,144。每项按该项原报告比较修改前后两轮；TTFT 与 TPOT 为两轮均值，吞吐为两轮合并值。实验使用不同版本、时间和开关组合，差值不可相加。两轮结果不保证稳定收益，也不代表所有输入、EOS 和缓存状态的正确性。

## 尚不能给出单项收益的能力

- 学习式 DSpark、Markov、confidence 和目标验证已运行，但没有覆盖所有输入与调度形态的单因素端到端收益；[变长目标图](20261030-dspark-shape/README.md)的 4K 校验差异及非有限值尚未完全解释。
- [YOCO 官方元数据和注意力](20261030-replay-semantics/OFFICIAL-ALIGNMENT.md)已有合成输入及单设备对照；[完整模型中间张量](20261030-replay-semantics/MODEL-TRACE.md)仍存在后续索引差异。Q 投影形状候选为诊断用途，未测端到端性能、未采纳。官方 NVIDIA 注意力内核未在 910C 执行。
- [SparseFlashMla](20261030-sparse-mla/README.md)当前 BF16 绑定已使用；新版混合量化要求的接口、压缩比与本模型现有缓存不同，固定镜像缺少相关 Python 模块。没有本机等价性或性能数据，不能宣称无法适配所有版本，也不能估算收益。
- 动态批处理、正常 EOS 与混合请求、在线 EPLB、通用采样以及可选 token 黑名单尚未全面验收；它们不应被当作已验证的加速。正常 EOS 的局部 256 重放候选有单独[两轮数据](20261030-yoco-normal-eos/LONG-OUTPUT.md)，但该条件使 DSpark 预发回退，不可与 ignore-EOS 基线直接混比。

## 整体比较

2026-10-30 在同一服务器先后运行两种服务，各测两轮；[完整比较及限制](../comparisons/20261030-910c/README.md)记录了预热、缓存命中、输出及原始证据：

| 服务 | 轮次 | TTFT ms | TPOT ms | 输出 token/s |
| --- | ---: | ---: | ---: | ---: |
| DeepInfer | 1 / 2 | 671.2 / 587.7 | 12.3 / 12.2 | 608.90 / 605.91 |
| vLLM Ascend | 1 / 2 | 2509.0 / 784.3 | 14.6 / 14.0 | 462.53 / 525.21 |

按对应轮次，DeepInfer 吞吐高 31.6% 和 15.4%；两侧每轮完整输出文本一致。vLLM 首轮 TTFT 异常波动原因未明，分词内部复用、逐请求 KV 命中和输出 token ID 未证实；因此这是有明确限制的同期对照，不能推广为稳定的通用优势。
