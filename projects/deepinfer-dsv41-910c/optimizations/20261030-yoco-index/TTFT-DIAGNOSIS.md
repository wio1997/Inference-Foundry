# YOCO 索引候选的首 token 时间分析

分析时间：2026 年 10 月 30 日。依据此前同一候选服务的四轮原始请求、API 时间戳和两个 DP 的运行记录，复核索引提前准备开关的首 token 时间差异。原测试依次执行关闭、开启、开启、关闭；每组为 32K 输入、1K 输出、并发 8，实际 KV 命中 235,904 token。

## API 分段

| 配置 | 轮次 | 请求到组批完成（ms） | 组批到任务发布（ms） | 发布到 worker 首 token（ms） | worker 首 token 到前端输出（ms） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 关闭 | 1 | 27.48 | 26.15 | 611.21 | 0.94 |
| 开启 | 1 | 26.85 | 26.05 | 536.61 | 0.57 |
| 开启 | 2 | 26.09 | 26.13 | 542.68 | 0.59 |
| 关闭 | 2 | 25.45 | 25.56 | 535.08 | 0.90 |

首轮开启与关闭的差异主要出现在任务发布后至 worker 返回首 token 的区间。该区间由 API 单调时钟计算，与 AISBench 首 token 时间的测量起点不同。worker 自身的 elapsed 采用另一计时起点，不能与这些区间相加。

| 配置 | 轮次 | DP0：Engram 第 1 层（ms） | DP1：Engram 第 1 层（ms） | DP0：prefill 主机总提交（ms） | DP1：prefill 主机总提交（ms） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 关闭 | 1 | 68.30 | 71.20 | 552.88 | 559.12 |
| 开启 | 1 | 14.97 | 14.29 | 483.06 | 477.10 |
| 开启 | 2 | 13.74 | 14.65 | 477.26 | 475.57 |
| 关闭 | 2 | 14.25 | 15.83 | 481.37 | 476.03 |

首个关闭组的第 1 层 Engram CPU 区间比其余组高约 53–57 ms。该区间可能包含异步设备操作、同步和其他隐式等待，不能将其视为 Engram 算子自身耗时，也不能据此断定索引开关造成了差异。四轮执行次序固定，缓存和首次请求效应仍是需要验证的可能因素。

## 处理方式

不依据首轮数据采纳索引候选。追加反向顺序的同服务对照，先开启再关闭，继续核验实际缓存命中、16 个 rank 的索引执行和完整输出。反向顺序可提供顺序影响的证据，但不能单独确定等待原因；保留路径、数据和回退方式均不变。
