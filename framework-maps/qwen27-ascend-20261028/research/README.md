研究新增显式请求/step观察、FX/graph任务标签、SDK复制导出审计与地图显示。诊断插桩时长不加入主计分。SG冻结底座含packed映射、offset装载、GDN状态布局正确性修复及FIA；这些不是本轮新优化采用。没有可交付的调度优化分支或新收益声明；需要复核诊断实现时，按EVIDENCE中的源文件/代码包SHA恢复。
