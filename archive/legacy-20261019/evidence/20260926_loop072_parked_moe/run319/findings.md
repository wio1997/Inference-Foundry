# Run319 — source gate for parked-tail full MoE candidate

**Superseded shape assumption (Run320–322):** The `[N,4096]` discussion below describes the module's input abstractly, but its first executable design assumed N=96 at layer4. Run322 measured local N=12 with global96 outer context under FlashComm1 and MoE ALLGATHER. The recommendation for a nested N_active×8 context does not apply to the current smaller post-gather routed-only B; keep global96 context and original collectives. See Run322 findings and Loop072 design before implementing a candidate.

Source review at pinned hashes (`source_sha256.txt`), no service or timing. Frozen config has 43 layers, `num_hash_layers=3`, so layer4 is a non-hash routed MoE with 256 experts, topk6 and one shared expert. `DeepseekV4MoE.forward` first `sequence_parallel_chunk`s its `[N,4096]` input, then invokes router and the complete `FusedMoE` path, and restores the token dimension after final collective. `AscendMoERunner.no_shared_forward_impl` covers prepare, quantized experts and finalize; shared expert runs on its own event stream. A candidate that times only GMM or Host enqueue would miss the relevant critical path.

**Required context correction:** `set_ascend_forward_context` chooses MoE communication method and padding from `num_tokens`/`num_actual_tokens`. EP prepare calls `maybe_all_gather_and_maybe_unpad` for hidden and router logits, and finalize calls `maybe_pad_and_reduce`; these inspect the current forward context. Merely slicing rows inside the original 96-token context is not a valid B branch. A compact B needs its own correctly bound context with `N_active*8` tokens (TP8 divisible), complete all-rank collective participation, and an independent Graph capture/dispatch key. The outer original context must be restored before the real model continues.

**State and semantics checks before performance:** grouped topk is per token at the model interface, but routed capacity, native dispatch, shared-expert stream, per-shape quantization and communication may change numerical results. `AscendMoERunner` can mutate `moe_load` when dynamic EPLB heat collection is active; the live fixture must assert the feature is disabled or snapshot/restore it. Verify no other persistent module state changes across A/A/B/A. Compare active router topk/expert IDs, finite outputs, output tolerance defined from A/A and frozen correctness, and whether inactive rows only touch work that can safely be omitted. All ranks must choose the same active mask and execute identical collective sequences; zero-active edge is a separate test. Native Graph support for each N_active shape is not yet established.

**Decision:** source gate passes only as a conditional design; no ready B implementation, correctness or speedup. Next implement a reversible eager-carrier hook at real parked layer4 entry with independently captured private A/B Graphs and nested compact context; fail closed on differing masks, unexpected EPLB state, shape, HCCL order, Graph capture or A/A variation. Historical R14/R35 are method priors, not current verdicts. `design.md` freezes the experiment.
