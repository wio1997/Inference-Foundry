**Result:** a complete reversible two-cycle snapshot is **not yet established**. In particular Target metadata, Draft cache and Host mirror state are outside `RuntimeAssets.snapshot_pages`; Run315s conditional typed-page result is insufficient. An immediate B→B service intervention would repeat Run285s uncertain side-effect problem. The next experiment should be a bounded **read-only real-cycle write/alias census** for both adjacent cycles at early stable state, compression boundary and first parking edge; derive a conservative backing-byte union and explicit host/device metadata register. Then implement A→A repeated restoration before B→B. If that census cannot close all domains, mark the owner hypothesis unresolved and redirect to a larger measurable schedule/resource gap rather than another synthetic start scan.
