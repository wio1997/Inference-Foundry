# Native model-cache qualification observer candidate

Source only; no complete model/cache runtime acceptance yet. Extends the R157 service integration to 15 overlays by adding an explicit request/group context around the native whole-segment send-thread put and a callback immediately after the original native MMC batch put returns. Flag FLASH_NATIVE_CACHE_QUALIFICATION=0 retains the original native put and never imports the observer through these call sites. No key, address, cache policy, gate, parameter or native SDK algorithm changes.

Flag 1 is diagnostic only and excluded from performance. It records actual put return codes; known-key existence, object size and native media fields; and full-byte readback of up to two actual objects per native request/group/process, into a separate registered NPU uint8 scratch (128 MiB maximum per object). Matching ordered SHA256 values for every original logical byte range, split into bounded 8 MiB pieces, prove all sampled bytes. Raw tensors and input text are not persisted. Unknown tier names remain null. Every callback failure persists a failed record. The qualification analyzer must require nonempty successful records and actual all-worker/group coverage. A None put wrapper return is never evidence of success.

Eight CPU checks cover request scope lifetime, concurrent send tasks, native errors, metadata-size mismatch, sampling bounds, discontiguous ranges, and the original flag-0 call path. SDK and readback are mocked in those checks; actual NPU readback is unqualified. The observer uses the original native register_buffer/get_into_layers/COPY_G2L=1/unregister_buffer API; runtime return and doc determine unregister status rather than guessing a void return. Original producer event synchronization remains before put; no extra synchronization or hash copy is permitted in formal mode.

P uses local TP8 cache keys; D metadata-only load/put are disabled. Do not enable the generic dense-only TP-mismatch cache path for Flash hybrid state. Cross-TP actual model PD remains the native Mooncake connector's responsibility and requires separate qualification. Native lifecycle remains unchanged; source audit found no-op facade shutdown inherited from core. Actual all-worker/API/container/Meta exits and drained operations must be observed before any lifecycle claim. R150/R154 model numeric failures remain failed. No 80K/600 or formal requests are issued by this source package.
