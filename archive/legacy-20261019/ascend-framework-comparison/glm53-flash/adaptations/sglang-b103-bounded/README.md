# GLM-5.3-Flash bounded SGLang B103 adaptation

These are the exact readonly source bindings of the accepted unit recorded in `provenance.json`. Apply only to the pinned image and verify every source SHA. The argv files describe the qualified bounded profile. Source files retain their upstream license headers.

New deployments require a fresh unique run directory, frozen identity/configuration review and one execution through local ZCode DeepSeek under EXECUTION_CONTRACT.md. Historical launchers and locks are never replayed. Native 15-second shutdown watchdog and numerical gates remain unchanged.

This package does not establish production service, cancellation, long-context, graph, MTP, cache, multimodal or performance qualification.

`runtime-profile.json` records the actual per-role environment and resource bounds. `input-fingerprints.json` contains only synthetic input identities; raw requests and responses remain local. `patches/` explains the native receive fix and selected mHC/SDK changes with exact base and candidate SHAs. The complete40-file source set is in `overlay/`; selected patches alone are not the whole adaptation.
