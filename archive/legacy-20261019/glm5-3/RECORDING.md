# 按需参考：怎样留证据

有结论的研究在 `records/` 留简短记录：问题与改动、比较条件和代码版本、原始结果位置、结论与局限、下一决定。已有信息用链接复用，无需为普通编辑或本地测试建立性能 Run、状态机或填完整模板。

性能比较需核对有效工作量、实际路径和测量噪声。估计、CPU 测试、设备片段与业务吞吐分别表述；局部加速不自动证明端到端收益，多个收益不能直接相加。正式性能计时与重型 profiling 分开。

旧 Run、patch、manifest 和 hash 保留原件；新的解释引用原证据。权重、凭据和大型 trace 不提交 Git，记录可追溯位置即可。研究阶段缺业务验收不抹除已有局部事实。
