# 我们要解决什么

以 **GLM-5.3 W8A8 / Ascend 910C 超节点**为目标，在指定业务请求范围内获得**更快的 TTFT、TPOT 和更大的有效服务容量**。固定资源与请求分布，比较同负载下的延迟，以及同延迟要求下的可持续有效吞吐；不能默认通过放宽延迟换吞吐。当前验收保持模型语义和精度、使用现有正确算子；这是本轮范围，不是物理极限。范围外方案可提出并说明取舍，实际采用以用户授权范围为准，不能自行改掉验收。

优先复用 SGLang 作为研究起点，现有 vLLM 业务保留。框架提供实现和基线，不替我们定义设计空间。本线研究执行机制，静态参数搜索由用户另行安排；参数对照可支持诊断和公平比较，不占据研究主线。是否改代码、是否动态输出一个参数，都不能单独判定研究价值。

底层研究对象是：为了交付同样正确的服务，计算与数据移动如何组织、状态如何表示和放置、哪些依赖与等待确实必要。资源需求和执行组织均可改变；允许多用一种资源以节省另一种或缩短等待，不能把填满显存、提高利用率或单项消耗最小当作最终目标。

方案可来自观测，也可来自整体重设计；选择能分辨关键假设的证据决定下一投入。允许未知、跨模块组合和暂时没有单项收益的中间实现，不要求先证明优化空间。性能上下界按需帮助判断，不是研究前置任务；有限探索不保证全局最优。具体判断见 [PLAN](PLAN.md)。

最终比较相同业务约束下的延迟与有效吞吐，同时检查正确性和实际完成的工作。输入输出长度、到达负载与缓存状态可变化，不能只验收一个固定长度点；多指标取舍显式报告。局部提速只证明其适用范围；本轮标准 PD 验收仍需完整 P→KV 传输→D 验证，PD 本身不是所有设计的先验最优。当前缺项见 [HANDOFF](HANDOFF.md)。
