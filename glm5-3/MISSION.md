# GLM-5.3 执行系统研究合同

## 目标与边界

在模型语义、正确性、精度和设备资源约束下，研究可执行计划如何逼近可达性能；最终以真实动态服务的延迟和有效吞吐验收。框架名称、现有类层次、当前算子发起顺序不是不变量。

输入为模型必要依赖与状态合同、算子实现集合、真实 shape/路由/KV 条件、硬件拓扑和资源成本。输出为可执行候选计划、因果证据、适用范围及无法回收的剩余时间。有限候选中最佳不能称全局最优。

| 固定合同 | 可探索决策 |
|---|---|
| GLM-5.3 数学语义、权重/精度身份、必要状态依赖 | 切分、布局、已有算子的组合和调用组织 |
| 给定实验的有效输入输出、拓扑和资源配额 | 映射、资源分配、通信发起/等待、并发顺序、buffer 生命周期 |
| 对外动态请求、结束/取消、KV 和 MTP 提交语义 | 调度策略、图档位选择、控制与设备执行边界 |

当前使用现有正确算子，不把新 kernel、精度改变或减少必要计算混入执行计划收益。并行拓扑变化属于另一实验合同，不能与同条件代码收益混账。

## 三层验收

1. **执行计划**：必要依赖和资源约束合法，CPU callbacks 的明确输出一致。只验收实验工具。
2. **真实片段**：实际算子与布局命中、设备完成时间、数值/状态正确；替身对原模型的瓶颈及干预响应已校准。只验收声明机制与范围。
3. **完整产品**：标准 P Prefill → KV Transfer → D Decode；动态请求和完整功能有效，同合同下可重复的真实 E2E 与 SLO 成立，才提升产品 Current。

第一、二层无需先建完整服务；第三层不能由模拟、短请求、局部 TPS 或 D 本地完整请求 fallback 代替。

## 负载与指标

保留历史正式产品用例：输入 **80000** token、输出 **600** token、共享前缀比例 **0.93**、声明 KV 命中率 **0.93**。共享前缀、实际 prefix-cache 命中、D 外部 KV 传输命中分别记账；目标值不是实测值。既有数值 SLO 未从发布入口完整恢复，当前记 **unknown**，不自行补阈值。

这是回归与产品验收的一项，不是 runtime 写死输入输出的许可，也不足以覆盖客户负载。另保留可变长度、混合并发、上下文增长和突发到达场景；按机制选少量保护用例，不盲目展开矩阵。

记录有效工作量、TTFT/TPOT/尾延迟、错误/拒绝和队列行为。启动/编译/加载成本与稳态性能分开；复用驻留实例和短窗口降低实验成本，不改变请求语义。
