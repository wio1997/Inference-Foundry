# Task-local AISBench adapter

Current workload (user update, 2026-10-07): input **80K = 80,000 tokens**, output **0.6K = 600 tokens**, shared input prefix **93%**. `config.py` defaults and new formal commands use `--input_len 80000 --output_len 600 --repeat_rate 0.93`; the SLO analyser defaults to `--expect_output_len 600`. CLI arguments still override defaults. Historical frozen commands/results retain their original lengths and must be analysed with their original expected output length explicitly.

The 93% value describes shared prompt content. The user separately specifies **93% KV cache hit rate** as the workload condition. Record the actual tokenized request length after chat templating, prefix warmup and observed cache reuse in the frozen Run; `HitRateCollector` measures native HBM and external prefix-cache counters separately. Do not fill the measured result with the declared 93% value or equate D external KV loading with P prefix-cache reuse. These defaults do not declare a tested concurrency or stable service capacity.

Every round generates a fresh `cache_salt`, shared by that round's prefix warmup and full phase. Keep the dataset seed fixed for matched comparisons; never reuse a previous round's namespace. This prevents a previous full prompt from raising the next test's prefix hit rate toward 100%, while retaining deliberate within-round prefix reuse. `round_<n>_cache.json` records the namespace, before/after counters and rates for each phase. Result rows include per-endpoint counters: P and D may both report engine=0, so legacy combined DP/total columns cannot establish the 93% condition. Zero queries mean an undefined rate. Counter resets/missing endpoint data invalidate the measurement. Salt isolation does not prove a particular achieved hit rate: block alignment, chat templating, admission and eviction still require measurement. Only reset prefix caches at an owned idle boundary before controlled warmup if physical cache state must also be matched; do not reset while PD export/transfer holds KV references.
