# GLM 研究协作

- 研究目标见 [MISSION](MISSION.md)，续接进度见 [HANDOFF](HANDOFF.md)。按任务读取相关代码和证据；定点修改无需通读研究资料。
- 从模型语义、数据依赖和硬件资源判断方案。可以复用、修改或替换框架实现；框架当前调用顺序不自动等于必要依赖。
- 本线研究执行机制；用户另行安排参数搜索。参数对照可用于诊断和公平比较，不展开配置扫描。方法由问题决定；独立执行器、模拟器、完整理论证明和多代理流程都不是前置任务。
- 节约时间和 token：优先复用证据，用能影响下一决定的实验推进。记录简短结论与证据位置；停止无信息增益的重复实验，不限制有依据的新探索。
- 区分估计、局部实测与业务吞吐。保留比较条件和未知项；不把 toy/CPU 结果当 NPU 收益，不改写历史证据。
- **设备操作仍暂停**：用户明确恢复前，不连接现场、加载权重或发起模型请求/NPU 测试。离线分析、本地实现和相关检查可继续。
