# Local MC2 preparation: verified CPU semantics, source-only candidate

[Minimal patch](local_prepare/local_prepare.patch) replaces each prepare tensor_split over allTP ranks with the one mathematically identical local narrow. In the non-SP positive padding/divisible-TP branch, it prepares only the local hidden/router rows. A full valid local shard is cloned, preserving the old global-padding input isolation; partial/empty shards are padded locally. No zero-buffer cache, router-output cache or shared mutable output is introduced. SP logic, mask values, global padded shape, collective/group/order, routing, quantization and finalize remain. No-padding/fallback selection also uses the equivalent local narrow; it is part of the diff.
