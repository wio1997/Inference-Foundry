# 调优头脑风暴记录约定

本目录保存跨模型优化想法，遵守仓库根 AGENTS 与用户当前目标。

- 开始新记录前读本目录 README，复用已有主题和 ID，避免重复条目。
- 默认使用中文，先写当前做法和候选改法，再写源码与技术细节。复杂逻辑可加本地可打开的 HTML / SVG 图解。
- 明确区分现有能力、候选代码改动、近似策略和配置对照；不要把已有策略写成新增发明。
- 源码证据使用固定 commit 和路径；当前上游与实际运行镜像分开记录。
- 没有同条件测量就不填实际加速比、不写“已优化”。局部 CPU 改善、设备空洞、端到端改善分别记录。
- 每个想法至少写新增成本、可能回退的场景、正确性边界、最小验证与否定条件。教学数字标明是假设。
- 更新想法时同步 README 索引；实验结论追加到原条目并保留反证。
- 不将其他研究线的 Current、PID、KEEP 或 next_action 当成本线事实。落地到具体模型前，按根 AGENTS 选择目标作用域规则。
- 记录思路本身不改变研究线状态。后续执行实验或修改代码时，按用户已有授权和对应研究线规则推进，无需因本目录重复请求已获授权。
- 不记录密码、私钥、token 等凭据。大日志、权重与原始 trace 不放这里，用可访问的证据入口引用。
