60 MiB 表明采样中存在上下文，不能据此认定其运行了完整模型、训练或某种具体计算。运行器的通用错误字符串写作 `External NPU workload overlapped measurement`；它是保护分支标签，不能替代对实际覆盖区间的证明。

两次运行器均按预设只停止本任务客户端和服务。第二次 model guard、runner 与容器已终止，容器 exit137 来源为本任务保护停止；原始日志未显示 HC 行分片触发的致命异常。启动期的可选 `/v1/responses` SDK ImportError 不影响本次使用的 completions/chat 接口，不能当作此次退出原因。

## 有效结果与待验证项

- G42 原始四档已接受：247.7817 / 130.5071 / 84.2510 / 39.5832 token/s，均低于原生 vLLM。见 [完整对照](../g42/G42_all4_comparison.md)。
- G43 实际 16-rank HC 组件通过：256 个边界案例、1280 个实际参数组案例，最大 FP32 系数差 2.26498e-6，原门限 2e-5 未放宽；它不证明完整模型质量或端到端收益。
- 重试实例的精确 32768→1024 API 和独立 C16 返回标识 16/16 通过。有效 32K 初测的 warm16/formal32、实际 SQLite C16、输入/输出与 SHA 已核验，11 次采样未观察到外部上下文。
- 重试保留相同启动命令和 62 份运行载荷，但自动种子由 821228692 变为 827671776。该差异单独保留，不能称为全部有效配置字段相同；没有跨实例 bitwise 或单个优化因果收益结论。
- 没有完成 G43 的 64K、128K、256K 或重复性验收。通用模型质量/数值等价性未验收。

## 后续执行条件

已向用户请求 166 的独占时间窗口或另一台空闲 910C。当前不再自动重复加载；更换服务器时必须在该机器重测原生 vLLM，不能套用 166 的数字。现阶段可继续的工作限于离线源码、证据核对和组件准备，不启动新的 NPU 作业。

离线 G44 候选只将 Engram 的 lookup/WKV/gate 沿用既有 HC 行分片，保留完整哈希/历史及原始算子，并恢复 dummy 行为零。模型头信息确认两个 WKV 均为 FLOAT/BF16 `[25600, 6144]`。候选尚未部署、硬件测试或验证收益，未运行的 G44 源码不纳入本次公开已运行适配。
