# Run214: bounded one-layer MoE shadow capture design

No service, patch, NPU work or performance claim. Design uses Run213 measured local ABI, not the runner padded token count as MoE shape.

Target only model.layers.0.mlp.experts on the first eager padded88 prefill in A and B cohorts. The8 local tensors are11x4096 BF16, with hidden/router/shared input aliases, input_ids None and unchanged explicit layer name. W4A8/ALLGATHER/FlashComm1/shared multistream are frozen. Dynamic EPLB, LoRA and DP metadata are inactive in both snapshots. Keep the outer MoERunner.forward transforms and reductions in normal execution. A and B have distinct full input hashes, so they test input refresh.

A diagnostic wrapper may call the original custom-op exactly once for the serving result. The shadow branch receives a persistent clone of its input, preserving the observed three-way alias, and captures only the same custom-op body in one NPUGraph per rank. It must retain the graph, persistent input, two graph outputs and graph pool storage. All8 ranks enter the branch in the same layer and cohort. No attention or KV operation belongs to the graph. Additional MoE communication and events are diagnostic, not serving transitions.

For A, compare graph replay against eager A and an extra eager A-prime on copied input to quantify self-replay noise. For B, update the persistent input from the second real snapshot, replay the same graph, compare both outputs against eager B and eager B-prime. Check input hashes before/after shadow calls, output shape/dtype/alias, exact and max-absolute/relative difference, all-rank completion, and explicit no extra EPLB/LoRA/counter mutation. A service result must use only the original eager output. If graph capture or replay raises, log the error and stop the service; do not substitute graph output into serving.

This correctness/capture run is not a timing benchmark because extra eager calls, graph capture and synchronizations perturb cadence. Only if both inputs pass against eager self-noise and all8 ranks complete, run a separate low-overhead A/B/A-prime stage test charging input refresh and graph replay. Limit to one layer, one shape and one graph/rank; reject if branch needs attention/KV state, dynamic route-dependent collective order, or unbounded graph memory. No formal E2E until stage effect and Runtime exact state pass.
