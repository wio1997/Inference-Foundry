# Run315 — snapshot byte coverage preflight

Read-only source audit of `RuntimeAssets.snapshot_pages(strict=True)` and Run299 eight-rank typed asset registry; no service, model execution or performance claim. The method requires each cache name to be supplied or declared no-write and copies selected typed `index_select(0, pages)` rows. It clones every configured `mutable_tensors` row. It does **not** prove that the caller supplied every physical page written across two cycles, nor that aliased typed views use the same page set.

The executable descriptor audit `scripts/loop071_snapshot_coverage.py` checked page0, midpoint and final page for each of three selected layer2-related backings on every rank: 72/72 backing-page samples have a complete byte-interval union **if all co-backing views select that same page**. The 4160B indexer page is covered by a 4096B FP32 key view plus the adjacent 64B FP16 scale view; either view alone is incomplete. The two BF16 backings have 32768B single-view pages. This is an affine descriptor proof for the selected assets, not native write tracing.

Next build a two-cycle write-page union and verify identical page selection for both indexer views; include neighboring Target layers on shared backing, all Draft caches and MTP/topk/acceptance/parking/metadata mutable state. Add an A→A repeat/restoration gate before testing B→B. Any missing write domain or alternate Graph dispatch invalidates the experiment. Historical R08 documents older async state-update call order and R21/R28 resource-competition reversions, but older DP2×TP4 results are priors only. Evidence: `coverage.json`, pinned historical search, `runtime/assets.py` source.
