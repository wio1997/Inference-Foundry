## Necessary distinctions

For each resource q, a strict time relaxation needs both:

required_q(W0) >= W_minus_q;
service_q(I) <= C_plus_q * duration(I) + B_q.

Only then is max(0,(W_minus_q-B_q)/C_plus_q) a lower time bound. Use the maximum of independent resource relaxations; do not add them without necessary serialization. Required work, capacity and interval-boundary conventions must match.

- An attained throughput is a feasible operating point, not an upper bound on all possible service. Taking the fastest observation and calling it C-plus reverses the required inequality.
- Weight footprints, active rows, current reads/writes and library collective messages are not automatically mandatory under alternate scheduling/layout/fusion/reuse.
- Run578 bytes divided by Run577 time mixes trials and unsupported physical units. Run247 minus Run578 does not isolate necessary non-GMM work.
- Run613's216 flow joins improve ownership, not live value/read-generation necessity. Run614 is a design, not an acquired certificate.
- A fixed acceptance/output ledger names the workload; it does not prescribe current layer/operator/materialization boundaries. A fresh semantic computation witness still needs entry-result credit and a declared expression class.

Confidence is high in these evidence limits. No same-W0 numerical whole-resource inference can be repaired merely by adding a disclaimer to mixed-run arithmetic.

## Smallest new evidence that changes the model

**Immediate measurement:** add the Resource fields already specified by Run614 to its planned typed-KV packet. One actually consumed, unoverwritten layer43 context projection must join canonical input/state, exact quant/ownership, predecessor available results and the successor frozen workload. Unknown entry availability produces UNKNOWN; a valid reused/dead row produces NO_WITNESS without invalidating Scheduling evidence. Limit selected-row operand copies to128KiB/rank; no additional model call/collective/synchronization. This is not a request to repeat Run585 or capture the entire43-layer tensor state.

A pass can admit a partial W-minus in the explicit online fixed-expression class. It cannot establish compulsory HBM bytes, unrestricted algebraic complexity or a positive time floor if W-minus<=B. Its main value is proving a reusable freshness/credit rule; apply it to existing whole-pass semantic keys only where supported, retaining uncertainty elsewhere.

**Strict numerical endpoint:** the missing complementary acquisition is an applicable authoritative exact-board maximum capacity certificate, not another microbenchmark. Run462/590 already bound this search: core-count/current/rated-frequency APIs and nominal HCCS speed do not answer it; OEM download access was unavailable. Request/retrieve the exact-bin maximum engine issue/clock envelope including tolerance and finite in-flight/boundary B, or corresponding HBM/cut-interface certificate. Do not repeat those blocked fetches or unsupported APIs absent new access/information. No single local performance experiment can prove that universal maximum.

**Conditional Engineering convergence:** while the strict certificate is unavailable, retain existing matched fixture service as measured points in a conditional model. The next new *service* measurement should occur only after Run614 identifies one legal edge and complete touched-state ownership: replay that bounded branch/intervention with the same operands/state under production residency and actual concurrent neighbors, verify outputs, and measure observer OFF/ON/OFF. This addresses transfer/contended-service uncertainty that Run577–580 could not resolve. It is not a new capacity-ceiling proof. Do not repeat the already rejected whole-chain GMM/HCCL overlap.

There is no honest one-shot experiment that closes the whole interval: necessary work/traffic, physical maximum service and legal scheduling are independent missing certificates. Each proposed acquisition should record which of those it reduces. Continue a complete conditional model with explicit unknowns rather than freezing Bound work until a universal ceiling is known.
