A PASS means only that a selected context writer is the last certified writer of one physical cache row before one named ABI-eligible reader in the declared same-stream execution. It requires externally authenticated same-acquisition flow, complete alias writes, cache lifetime and reader ABI/coverage. The Boolean flags in a synthetic packet do not authenticate those facts. The reducer does not prove the earliest reader, actual physical HBM read, fresh unavoidable projection, compulsory materialization, necessary HBM bytes or a Scheduling time floor. A query overwrite returns NO_CONTEXT_WITNESS; absent flow/coverage/lifetime or unknown sentinel returns UNKNOWN.
