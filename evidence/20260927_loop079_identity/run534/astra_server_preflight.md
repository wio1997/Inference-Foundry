## Mandatory corrections before launch

1. **Make borrowed-source installation/restoration atomic per file.** Both use `Path.write_bytes`, which truncates the destination before completing its write. The saved-original/expected-patched mixture test covers interruption *between* files, but not a crash *during* a write. A torn current file has a third SHA, so the deliberate third-SHA restore refusal prevents automatic recovery. Write and fsync a same-directory temporary file, preserve source mode, then replace atomically; persist originals and manifest durably before the first replacement. Keep refusal of genuinely unexpected edits. Add a CPU fault case at the pre-replace/after-replace boundaries and verify that every destination remains one of the two known hashes. Restore should also require the exact expected source-key set. An independently changed helper should invalidate admission, but must not prevent restoring verified borrowed source backups after service shutdown.

2. **Correct the API identity label.** `api_consume(res.request_id, request_id, ...)` calls its first value `internal_id` and emits it as `request_id`. In this source, `RequestState._new_request_output` explicitly sets `RequestOutput.request_id=external_req_id`. It is the response/external identity, not the Scheduler/EngineCore internal ID. Rename that field (for example `output_request_id`), and join the true internal identity using `output_add_request`/`output_receive`/`output_queue`. Require the external ID equality appropriate to the single-choice frozen branch, rather than pretending this is an independent internal→external observation.

3. **Supply an auditable complete-record gate.** `flush(reason)` currently discards reason, emits no batch/terminal row count or digest, and merely clears the process buffer after append+fsync. Add terminal/batch metadata with sequence range, count and bytes digest, or implement an equivalently strong reducer proof of complete sequences and all expected terminal events. A clean JSONL prefix must not pass after a lost terminal flush. Require run-specific empty output paths or a process-instance identity so PID/file reuse cannot silently concatenate acquisitions. Truncated JSON, sequence gaps/duplicates, unknown phase, missing all8 cohort, lost request and missing DONE must reject admission.

4. **Finish and independently admit the actual controller/reducer before live execution.** Run529 explicitly provides an interface, not these gates.
