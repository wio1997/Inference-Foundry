# Run338 — private warm-prefill MoE Graph hook did not reach the module

The original Extreme 8×910B3 DP1×TP8 DSpark7 FULL Graph service completed 48/48 warmup and 12/12 measured requests, all exactly 1024 output tokens. All eight measured Runtime reports passed in FULL Graph mode. The runner command exited 0; the reversible ModelRunner patch restored source SHA256 `004dbd0d5b1a5c3f9533fa1d12327bd0ae421fe24bb2674544b2c4a25d74aaba`, stopped the service and returned HBM to about 3.4 GB/card. The measured one-cohort 575.729 tok/s is diagnostic and does not alter formal Current 571.681 tok/s.

The intended first measured padded88 `_model_forward` hook installed a temporary wrapper on `runner.get_model().model.layers[4].mlp.forward`. **No rank produced a fixture report**, and no private A/Graph B/A2 samples were collected. The client and Runtime success do not validate the proposed Graph mechanism. Since Run337's outer `_model_forward` hook did fire under the same four-cohort trigger, while this inner module wrapper generated no report and the service completed normally, the likely explanation is that the active compiled prefill callable bypassed the Python `mlp.forward` attribute patched after compilation. This is an inference from control flow and missing fixture, not a source-level proof of the exact compiled callsite. There was no observable live output substitution.

Decision: **INVALID instrumentation gate**. Do not reuse the measured client TPS as a performance comparison and do not classify original prefill MoE Graph as KEEP or REJECT. A further layer-local test needs a hook at a proven executed boundary or a fixture constructed before compilation; it must avoid assuming Python module monkey-patches intercept the compiled prefill. An existing whole-model prefill Graph mode may offer a more direct, current product-path test, but requires a separate shape/memory/state preflight and historical Graph evidence review before intervention. Alternatively continue reducing the Resource/Hardware Bound uncertainty with exact-payload TP8 HCCL capacity measurement after confirming CANN 9.1.0/driver 26.0.rc1 applicability. No numeric Bound changes.

Evidence: `warmup48.json`, `measured12.json`, `runtime/rank*_cohort5.json`, `patch_install.json`, `patch_restore.json`, `stop.log`, original fixture and runner scripts. The API shutdown log after measured completion is associated with scripted service stop; it is not evidence of a fixture crash.
