# GLM-5.3-Flash bounded lifecycle adaptation

R116 cancels a real 2379-token P/D request while its native 68-vector KDA SDK write is held. It retains the source and destination owners until the actual SDK write drains, a unique native ACK arrives, and the native TP16 MIN fences allow release. Five fresh normal requests then reuse the native request, Mamba, metadata and physical KV allocations.

The frozen independent validator passed the complete unit: exact output IDs/text/EOS, the original logprob gates, imported mixed states, 1,917,181,056 SDMA payload bytes, 32 native manager/SDK closures, 320 shutdown phases, and both containers exiting 0 with eight idle cards each. All 16 ranks reused all 19 original physical pages naturally within a 24-page pool. Expected cancellation HTTP 500 responses are excluded from successful generation and goodput.

The files are:

- `overlay/`: all 41 exact accepted source bindings; upstream license headers are retained.
- `patches/` and `patch-manifest.json`: eight changes against the separately accepted R113 source, with base and candidate SHA256 values.
- `runtime-profile.json`, `argv46.json`, `argv47.json`: the actual environment, resolved arguments and resource limits. This unit uses C1, context 4096, capacity 3072, page/chunk 128 and the native 512-token reserve.
- `evidence/`: acceptance provenance and a small result summary. Raw requests, output text, logs, weights and binaries are excluded.

Deployment requires the pinned B103 image, model/quantization/tokenizer identity, exact source hashes, a fresh owned namespace and request book, and a new frozen review followed by one local ZCode DeepSeek execution under `EXECUTION_CONTRACT.md`. Never replay historical launchers, locks or write-gate release files. The native 15-second watchdog and numerical gates remain unchanged.

This is a bounded diagnostic profile. It still uses an immutable RID/room book and per-vector CPU/HTTP byte auditing. Actual completion reorder, ordinary caller service, arbitrary peer-crash failure shutdown, real 80000-input/600-output operation, graph, MTP D5, cache/L3, vision and formal performance remain unqualified. Earlier C2 model qualification is recorded separately in the R113 package.
