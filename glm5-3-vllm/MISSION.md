# 研究目标

面向 **GLM-5.3 W8A8C8 / Ascend 910C**，保持约定正确性与服务质量，获得更快的 TTFT、TPOT 和更大的可持续有效服务容量。既比较同负载延迟，也比较同延迟要求下的吞吐；输入输出可以是业务分布，不默认固定长度或放宽延迟换吞吐。

当前优先复用用户认为更稳定的 vLLM-Ascend 环境。稳定性判断来自用户观察，尚无本线的配对测量；不据此宣称 vLLM 或 SGLang 的最终性能上限更高。研究计算与状态如何表示、放置和推进，允许以一种资源消耗换取另一种资源或等待的减少。

当前保持模型语义与 W8A8C8 精度要求，使用已有正确算子，不开发新算子或用削减模型能力取得正式收益。算子接口须实际支持候选的布局、分块与异步方式。范围外想法可提出并说明需要的能力；参数扫描由用户另行安排。

研究可以改变现有执行图、批次、状态所有权、缓冲区和同步边界。减少层数或提取片段只用于缩短验证周转，不改变最终模型目标。正式服务目标保持 PD 分离，包含排队、P→KV 传输→D 和资源争用；两机共置运行不代替 PD 验收。两台研究设备限制当前验证范围，不自动改变产品目标。

必要代价与有效性能界用于判断机会，不是探索前置条件。当前实现的工作量不自动属于所有合法实现；实测可以推翻成本假设。只有覆盖声明范围的有效界与可达结果足够接近，才能声称接近最优；有限搜索和预算耗尽都不是全局最优证明。

2026-10-17 用户新增约束：设备内、节点内、节点间和 PD KV 数据搬运全部使用 SDMA；确认实际选路及 communicator 级覆盖，控制/初始化通信另记。SDMA 不支持的接口或候选需要明确证据，不静默改用 RDMA/TCP 数据回退。
