# 按需参考：执行机制与快速验证

从同样正确、同样及时的服务出发，寻找更好的执行组织。最终实现质量与研究投入分别判断：实现比较服务效果，下一次实验比较它能带来的改进或有用信息。参数搜索另行安排，本线保留必要对照。

资源依据见 [硬件地图](HARDWARE_MAP.md)：区分拓扑、条件性能、竞争与接口能力，先校准会影响下一决定的部分。地图可被新证据修正，不将当前后端的可达性能冒充物理上限，也不等待完整地图才提出新机制。

## 借鉴算子优化，但不开发算子

以已有算子和通信原语为积木，研究工作划分、局部性、流水、状态生命周期与资源交换。允许改变跨模块组织；当前 trace 描述发生过什么，不证明这些工作不可避免。候选可以来自测量，也可以来自整体重设计。

候选简述改变了什么代价或执行关系、关键未知与判别办法即可。解释可暂不完整，允许组合原型和不立即提速的中间实现。代码确实变快不自动证明原解释；结果与预测不同，就更新解释。一次失败只否定证据覆盖的方案，没有信息增益的重复实验应停止或转向。

分别识别模型语义依赖、现有算子接口约束、框架附加同步与资源互斥；由待检验的机制决定片段边界，允许跨模块。改变执行组织后重核请求关键路径和稳态瓶颈。机制若改变配置的可行范围或最佳点，向参数组说明相关变量并做必要的少量对照，不能仅用旧配置判死新机制。

## 按结论依赖裁剪实验

优先缩小参与实验的模型范围，保留可能改变结论的因素。下面是非穷尽的参考，不是必经阶段。

| 研究对象 | 可用的最小实验与限制 |
| --- | --- |
| CPU 队列、数据结构、状态与元数据 | Mac 可检查逻辑；部署耗时要在相关 CPU、并发和工作集下确认。在线策略不使用未来信息，改变批次后不能沿用旧完成时间。 |
| NPU 执行组织、布局与局部重叠 | 提取真实层或相关相邻层，只加载必要权重。保留目标 shape、量化参数、状态和算子路径；片段输出与原路径对照。改变布局、批次或并发后重新判断成本。 |
| 跨节点通信与状态迁移 | 保留必要 rank、消息量、拓扑与竞争；可以多机仅加载几层。少量设备可测目标布局的局部片段，不能用虚拟 rank 证明真实多机吞吐。 |
| 调度闭环、容量与完整服务 | 在声明的部署、负载和缓存条件下测排队、成功率、TTFT/TPOT 与持续有效吞吐；PD 还包括 P→KV 传输→D。片段收益需确认在完整服务中成立。 |

删层后的模型可辅助联调；减专家、top-k 或隐藏维度会改变路由、分组矩阵和通信，不能默认代表目标模型。不要让删层模型的自由生成代替完整模型的真实输入分布，也不按层数乘回整模型收益。反复复用同一层权重可能改变缓存行为；只占满空闲显存也不能恢复真实访存与竞争。

真实片段按候选需要保留输入、残差、位置、KV/index 状态或路由信息；若候选改变其中某项，应重新计算或保留能重建它的输入，不能用旧输出绕过被研究的部分。保持结果语义，不固定原实现的物理排列与调用图。

## 减少每轮准备成本

只为选定问题增加独立测试入口，优先复用已有执行代码。入口需确认实际量化、算子、通信和图执行路径，避免绕过服务初始化后悄悄走到不同后端。纯执行片段不包含的 CPU 准备与排队时间不能声称已被消除。

允许时一次加载权重与初始化通信组，在同等状态下交替运行基线和候选；区分预热、编译/图捕获、正式测量，并避免缓存状态与其他设备作业造成干扰。通信组、worker 初始化、原生扩展或图结构变化可能需要重启或重新捕获，常驻不意味着任意代码都能热更新。

未校准模型可以探索假设与敏感性，数值不是实际收益证据；用于决策的预测说明依据与未知项。最终比较既核对各自配置是否合理，也核对测量路径与实际完成工作，不以配置扫描代替机制研究。

## 边界与记录

已验证可达吞吐、未知最优值与有效上界须在相同声明范围内比较。差距可能来自额外工作、执行低效或上界过松，不能全部当成可回收收益；局部界不证明全域最优。没有完整理论界仍可探索，实测反驳估计时修改模型。

每轮只保留后续需要的代码版本、条件、命令、原始结果位置、结论与关键未知；不为尚未进行的研究预建任务层级。基础通信条件结果见 HARDWARE_MAP；当前阶段、官方基线完善的收益和自定义执行机制的实测结论统一见 [HANDOFF](HANDOFF.md)，此计划不固定阶段性状态。
