# GLM-5.3-Flash w8a8 / Ascend 910C 实验源码

本分支包含 DeepInfer 适配源码及实验工具，保留上游 Apache-2.0 许可证。权重、镜像二进制和现场控制器均不包含在内。英文 README 给出镜像标签、已记录的本地镜像 ID、权重元数据哈希、依赖版本及子模块固定版本。`ce42…` 是本地镜像 ID；未记录可拉取的 registry RepoDigest，不能当作镜像清单摘要。CANN 的精确安装版本尚未独立确认。

`portable/launcher.py prepare` 读取交替对话 JSON、按模型模板分词并检查长度；`rank` 启动单个 worker。英文 README 提供参数化命令。现场测试由独立资源分配器持有共享锁、登记四个进程并核对宿主 PID 与物理 die 映射，全部核对后才写入各 rank 的 `go` 文件。公共代码尚不包含可替代现场分配器的完整安全门禁，因此当前不能声称一条公开命令即可独立部署。禁止在未确认独占授权与设备映射时运行。

四 rank 的一次限定实验中，输出 token 与同运行时基线一致，archive-v2 在 42 token 后恢复，最终生成 44 token 并由 154827 停止；该停止标记不同于 tokenizer EOS 154820。参考案例中的推理文本存在差异。独立整模型精度、生产 TP/EP、服务生命周期、长上下文及性能尚未验收。
