L103: # GetSocVersion
L104: 
L105: ##
L106: 
L107: Description
L108: 
L109: Obtains the version model of the current hardware platform.
L110: 
L111: ##
L112: 
L113: Prototype
L114: 
L115:     `SocVersion GetSocVersion(void) const`
L116: 
L117: ##
L118: 
L119: Parameters
L120: 
L121: None
L122: ##
L123: 
L124: Return Value
L125: 
L126: Enumeration class for the current hardware platform version model. For the mapping between this enumeration class and AI processor models, refer to the include/tiling/platform/platform_ascendc.h header file in the file storage path after CANN software installation.
L127: 
L128: Obtain the AI processor model as follows:
L129:   * For the following products: run the npu-smi info command on the server where the AI processor is installed to query the Name information. The actual configuration value is AscendName. For example, if the Name value is xxxyyy, the actual configuration value is Ascendxxxyy.
L130: 
L131: Atlas A2 training products/Atlas A2 inference products
L132: 
L133: Atlas 200I/500 A2 inference products
L134: 
L135: Atlas inference products
L136: 
L137: Atlas training products
L138:   * For Atlas A3 training products/Atlas A3 inference products, run the npu-smi info -t board -i id -c chip_id command on the server where the AI processor is installed to query the Chip Name and NPU Name information. The actual configuration value is Chip Name_NPU Name. For example, if the Chip Name value is Ascendxxx and the NPU Name value is 1234, the actual configuration value is Ascendxxx_1234. Where:
L139:     * id: Device ID. The NPU ID queried by the npu-smi info -l command is the device ID.
L140:     * chip_id: Chip ID. The Chip ID queried by the npu-smi info -m command is the chip ID.
L141:   * For Ascend 950PR/Ascend 950DT, run the npu-smi info -t board -i id command on the server where the AI processor is installed to obtain the Chip Name and NPU Name information. The actual configuration value is the Chip Name_NPU Name. For example, if the Chip Name value is Ascendxxx and the NPU Name value is 1234, the actual configuration value is Ascend_xxx_1234.
L142: 
L143: Here, id is the device ID. The NPU ID obtained by running the npu-smi info -l command is the device ID.
L144: ##
L145: 
L146: Constraints
L147: 
L148: To support operator binary reuse, when using Atlas A3 training products/Atlas A3 inference products, the enumeration value returned by calling the GetSocVersion API is the same as that of Atlas A2 training products/Atlas A2 inference products. If you need to distinguish them, use the aclrtGetSocName API.
L149: ##
L150:

L159:             // ...
L160:         }
L161:         return ret;
L162:     }`
