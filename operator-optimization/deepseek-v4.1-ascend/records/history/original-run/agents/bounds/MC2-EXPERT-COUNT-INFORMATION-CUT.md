# MC2 跨 rank 专家计数的信息下界：条件证明

## 冻结源码与证明对象

这是一个独立算子接口、特定输入域上的**最坏输入信息界**，不要求传统稠密 MAC，也不证明某次 profile 的时间界或整模型 TPS。冻结参考源码 `dispatch_ffn_combine_kernel.hpp:792–829` 先按 expert 路由并汇总各来源 rank，再把每个本地 expert 的跨来源汇总值复制至 `ptrExpertTokenNums`；这个值在后续 GMM 的 `maxOutputSize` 截断前。此前逐链审计、源码哈希及未绑定项见 [专家计数审计](../diagnosis/RECAPTURE-MC2-EXPERT-COUNT-20261029.md)。该源码未唯一绑定历史运行 binary；不要将下述接口假设当作历史调用的实测。

固定 receiver rank `r` 和一个不同的 source rank `s`，选取窗口，使 `s` 的对应路由选择在窗口开始后才由信息 cut 的远端一侧获知，且要求该窗口结束前 receiver 侧取得完整且精确的 24 项 count 输出。接收侧初态 `z`、receiver 的本地输入、其他来源数据、模型权重、共享随机种子与预处理状态均固定。`z` 不含任何区分下述源输入的副本、预先算出的 count 或等价摘要；若信息可由共享存储、第三方、host 或任何其他位置获取，相应传递必须纳入同一 cut。允许远端任意预计算和压缩、任意交互、融合及重算，不规定必须执行现有算子的过程，也不限定 MAC 算法。

我们人为限定以下合法独立接口输入域：source 至少有 1008 行有效、每行允许 6 个互异 expert ID；24 个标识属于接收 rank 的不同本地 expert，另外至少 6 个标识属于其他 rank；输入的 active mask 为有效，且每次运行的余下输入与输出初态固定。假设接口对这些人为构造的路由 ID 均精确产生真实计数，不发生 ID 截断或计数溢出。这里的“合法”是条件定义，不宣称固定网络 router 或历史请求可以产生这些组合。若端到端正确性并不要求 count 向量可观察、可被代数消去，则本界不自动约束端到端实现。

## 24 维独立计数构造

将 1008 行分成 24 组，每组 42 行。为第 j 组每行的 expert 列表固定五个相同的非本地 ID，第六项在接收端本地 expert j 和另一个固定的非本地 fallback 之间选择；两个固定集合互不相交，因而每行六项互异。设组 j 选择本地 expert 的行数为 `a_j`，可以独立取 `0…42`。源 rank 对 receiver 的 24 维 count 增量恰为 `(a_1,…,a_24)`；固定其他 rank 的贡献只加固定偏移，所以不同增量仍给出不同、精确的 count 向量。构造覆盖 `M = 43^24 = 1596772093453535767288998989560362112801` 个不同接收侧结果；不需要假设激活或权重具有任意可控的数值。

设跨 cut 所有输入侧→receiver 信息的完整二进制 transcript 长度最多为 b 位，消息边界、长度、顺序、结束标记、时序、静默等必须通过有限离散编码并计入 transcript，不允许无限精度的连续时间或免费控制侧信道。receiver 向 source 的交互消息由固定 `z`、先前 transcript 和固定随机种子确定，不能区分已有相同入站 transcript 的两个 source 状态；对随机协议，本结论要求固定该共享种子后仍对所选域零错误。至多 b 位、长度可区分的二进制字符串有 `2^(b+1)-1` 种。若两个不同 count 对应相同 transcript，receiver 得到相同状态，无法对两者都输出正确结果。因而对整个构造域的零错误协议，至少存在一个输入的入站 transcript 长度

```text
b ≥ floor(log2(43^24)) = 130 bit.
```

由于 `2^130 < 43^24 < 2^131`，若声称所有输入均最多 129 bit，则所有可区分 transcript 总数 `2^130−1` 仍小于 M。这个数是**最坏输入**下界，不是每个输入都必须传 130 bit；若某次结果提前为接收方所知，实际需要的信息可以是 0。它也不要求真的用可变长编码，更不证明 130 bit 是实际网络流量、数据包大小或带宽流量下界；长度、时序或其他信息载体的容量必须统一计入。不将多个 receiver 的各自最坏值相加，因为输入和链路可能不同或重叠。

若另有该完整 cut 对同一窗口任意前缀的严格总信息接收包络 `bits(t) ≤ β + B·t`，包括所有并行通道、控制信息与初始在途信用 `β`，则存在上述构造域中的输入使 `T ≥ max(0,130−β)/B`。`β` 以 bit、`B` 以 bit/s 为单位；其他重叠工作与该界取最大值，不无条件相加。`β`、`B`、实际可达输入集合、二进制绑定、count 消费与窗口初态均未知，因此不能代入 169 的数值。该条件界可能非常弱，不意味着它对实际预测有用。

CPU 可复算：`python3 -c 'n=43**24; print(n, n.bit_length()-1)'`。本证明是构造性信息论证明，不运行设备、不修改目标实现。
