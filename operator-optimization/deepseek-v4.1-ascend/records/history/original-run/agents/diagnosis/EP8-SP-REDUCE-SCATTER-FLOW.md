## 跨 rank 归约的信息界：独立接口条件模型（2026-10-30）

本节借用已保存 BF16 `[8184,5120] → [1023,5120]` 形状与八路切分建立**人工输入族**；引用的样本、host 栈和形状边界见 [F16 分析](../fusion/F16-TWO-PROJECTION-TILE-AND-ROUNDING.md) 及上文。它们不证明真实 collective 组大小、数据依赖、输出精度契约、独立输入可达性或 binary 身份，因此下文不是对这次 169 调用的实测通信下界。

### 接口及证明

假设八个 rank 参与一个精确 BF16 reduce-scatter，每个 rank 的源 tensor 对应 `[8184,5120]`，目的 rank B 必须在同一计时窗结束前按位准确获得自己 `[1023,5120]` shard 的逐元素归约值。取其中一个合法的输入子族：B 和六个远端 rank 的该 shard 恒为正零；第七个远端 rank 的每个元素在 16,384 个 BF16 正规正数编码 `0x0080..0x407f` 内独立选取。若归约的数值契约保证这些值与零相加后按位不变（这里不包括异常值和次正规数），B 的输出就恰好是这张远端 shard。这个条件输入族无需假设历史任务真实出现这些值。

元素数 `n=1023×5120=5,237,760`，每个元素恰有 `2^14` 种可区分值，故 B 需要能区分 `2^(14n)` 种输出。固定 B 的初态、其本地输入、模型状态、已完成的准备及独立共享随机种子，并规定动态选择仅在窗口开始后被源侧获知；B 的初态、窗口前完成的复制和其他旁路均不能已含这个选择。将所有可把输入相关信息送至 B 的路径合并为一个 cut，允许七个远端先聚合、任意融合、分块流水、重算和无损压缩。假设 B 的最终输出由其固定初态和 cut 上**完整、有限、离散且可解码的 transcript**决定，含控制、轮次、分帧、长度、终止及时间信息，不存在免费旁路；则不同的目的输出不能对应同一 transcript。

令 `m=14n=73,328,640`。即使允许 transcript 变长，长度小于 m 的所有二进制字符串也只有 `2^m−1` 种，因此至少一个合法输入需要不少于 **73,328,640 bit** 的完整 transcript。只说最坏输入，不能说每条输入或平均通信量都必须达到它。若通信 transcript 对全部输入统一使用固定长度 L，才有每次实际发送均为 L 且 `L≥m`。若使用立即可解码前缀码，最坏长度至少 m；在该 `2^m` 输入均匀且无额外编码侧信道等条件下，平均长度也至少 m，但非均匀输入不受此平均界约束。允许独立随机协议时，对每个同时保证全部有限输入精确正确的共享随机种子成立最坏输入界；不能推出某个固定输入对所有种子都需要 m bit。

**长度和时间不能免费补充无界信息。** 如果只计 payload，而外部的消息数、轮次或结束时间可免费区分不同情况，上述 transcript 计数不能直接变成 payload 下界。例如发送零 payload、以四种不同到达时间编码四个值，接收侧可区分四种结果；这是抽象时间信道反例，不是 169 实测。只允许一条消息且其结束可辨，且除了该消息具体二进制串及其长度没有任何其他信息时，长度最多 b 的 payload 仍只有 `2^(b+1)−1` 种，因此该特定、恰有 `2^m` 个输出的族里，最坏 payload 长度仍至少 m；这不说明每条消息都至少 m，也不能扩展到多次免费分帧或自由时间信道。若把长度/终止编码进同一个已计量的前缀码，就按完整编码位数计，不重复把同一控制信息加两次。

### 时间与重叠

若独立证明同一 cut 全部并行路径和所有计量侧信道的窗口前缀容量满足 `I(t)≤β+B t`，其中 `I` 以与上面 transcript 同口径的 bit 计，`B>0` 为硬容量、`β≥0` 为可证明的窗口初始在途/突发信用，且上述输入族中 B 所需信息必须在该窗内交付，则该族中至少一个输入满足：

`T ≥ max(0, 73,328,640−β)/B`。

该证书允许远端 rank 内部先归约，和计算、其他路径、不同块的传输重叠；若另有**同一个实现域、同一个完整窗口**的独立计算下界，两项取最大值，不能默认把计算与通信墙钟时间相加。长期平均速率或 profiler 单次实测速率不是这个短窗硬容量；已在窗口前交付并进入接收侧初态的信息不能继续当成窗内必需量。若初态随输入变化，应先限定相同初态下可能的剩余输入集合并重算输出像；不能既把已预传数据算入必需量又用信用重复抵消。

### 为什么不能套用到本次 F16 融合链

上述证明把一个远端 rank 的 5120 个 BF16 输出通道视为独立可变。若这个远端 shard 实际只由固定权重的确定性 `1024→5120` 投影产生，每一行输入只有 1024 个 BF16 元素，则即使允许所有 `2^16` 种 BF16 编码，其可能输入不超过 `2^(16×1024)=2^16384`；确定性映射后的输出种数不会更多。人工输入族却要求每行 `2^(14×5120)=2^71680` 种输出，因此它**不能全部由这个单 rank、固定权重的投影输入族生成**。这不排除七个 rank 同时变化时的其他结果，也不把 `2^16384` 的可达数上界当成通信下界；真实权重、上游可达性、实际舍入与参数、旁路和缓存均需另外证明。

同一次两个导出区间 460.751 / 706.88575 µs 分属不同记录类型和轨道，尚不证明是该精确接口的同一设备通信窗口或纯网络时间；硬容量 B、信用 β、实际分组及 tensor 身份未闭合，不能将它们与此符号界相除、相加或声称有多少可隐藏收益。输入族、模型语义与这一采样的关联有缺口时，本任务的真实数值界仍为 UNKNOWN。

纯本地 CPU 复算（不访问权重内容或设备）：

`python3 -c 'n=1023*5120; print(hex(0x407f-0x0080+1),n,14*n,(14*n+7)//8,16*1024,14*5120)'`，输出 `0x4000 5237760 73328640 9166080 16384 71680`。其中 9,166,080 只是上述位数换算成字节的算术，不是测得或必然的 HBM/TCP/链路字节。
