# F23 数值依赖与通信下界：独立审查

审查对象 `F23-COMMON-DEPENDENCY.md`；不修改原文。结论：**数值依赖证明在其二元、精确输出的条件下成立；通信的信息量计数也成立，但时间推论必须把“完成时刻之前的 transcript”和速率约束写得更严格。两者均不能直接作为 169 真实请求的通信下界。**

## 1. 数值依赖：成立，量词应保持原样

在所有坐标均可独立取 0/1 且输出 z 可观察的语义域，对任一 i，改变 `x_i`（固定其他量）可区分 0 与 1.5；改变 `y_i` 可区分 0 与 1。这证明 `∀i, ∃两组合法输入` 使该输出随对应变量变化，不是 `∀i, ∀输入` 都必须执行两次读取或某个乘加。原文的 BF16 小整数/半整数可精确表示；当 scale=1.5 且计算只涉及该小域，可能输出 0、1、1.5、2.5 都可精确表示。其他 dtype、一般浮点数、NaN、舍入顺序、真实路由与 shared 结果的可达性均不因此解决。

当 x=0、y∈{0,1}^N 时，z=y 是单射；因此若要求对全部 2^N 输入都精确正确，接收侧必须得到足以区分这 2^N 种值的信息。不能将这个扩大的独立输入域自动套到共享上游、相关性未定的真实模型，也不能把 z 可观察替代为最终 token 可观察。

## 2. 交互与可变长 transcript：计数成立的精确定义

固定接收侧初始状态与随机种子；发送侧 y 选择后，考虑**至接收侧产生规定输出的时刻为止**，接收侧因该次 y 通过 cut 可观测到的全部信息。要求存在一种统一、明确的有限二进制记录方式：

1. 同一接收记录连同固定初态、种子和既定协议，就确定接收侧输出；接收侧的发言可以是先前接收内容的确定函数，但不得额外看到依赖 y 的旁路。
2. 包边界、信号方向（若协议本身不能确定）、轮次、可变长结束、缺包、报文时刻、是否发送、错误/终止等凡能区分 y 的差异，都必须包含在计费记录中，或者被协议严格约束成 y 无关。不能只把数据 payload 串起来，却把分段和终止作为免费的额外符号。
3. 记录长度为实际记费的 bit 数。对于含多方向并行、不同物理链路的系统，需解释如何把所有有效信号映射为该记录，以及容量约束怎样适用于这个长度；并非任意“编码记录长度”都自动等于线缆实际 bit 数。

在这些条件下，不同 y 必须产生不同记录。全部长度小于 N 的二进制串共有 `2^N−1` 个；合法输入有 `2^N` 个，因此 **∃至少一个 y，其输出前记录长度 ≥N bit**。允许有的 y 长度小于 N，也允许交互和分块；结论仅是对这个协议、在该子域上的最坏情形。其量词是 `∀符合条件且全域正确的协议，∃一个 y`，并不是存在一个固定 y 对所有协议都要传 ≥N bit，也不是每次、均值或稳态请求都达到该值。这里不需额外假定 prefix-free；若实际协议另外要求即时解码或前缀码，需要单独分析，不能直接用本证明推平均长度。

如放开免费时间侧信道，结论可失效：以 N=2 为例，发送侧按 y 选择 4 个不同的约定时刻，只发送同一个固定信号，接收侧通过时刻解码 y；若只计 payload，这至多 1 bit，而时间承载了额外信息。若可以免费观察“完全不发送”或不同终止时刻，也可能编码信息。原文已声明排除免费时间和隐含终止符，本审查强调这些必须是**协议与计费模型的实际约束**，不能只在结论中补一句而在具体系统里漏记。

## 3. 从信息量到时间：需要补的两个条件

原文 `T≥N/C_cut` 在如下加强条件下可由上述最坏输入成立：

- 时间窗从所有可能 y 均共享的在线起点开始，到接收侧产出所需 z 完成；计数的是这个完成时刻之前的全部可区分信号。不能用输出之后的收尾 transcript 证明输出已经耗时。
- 所有有效信号的**累计输送约束**满足对每个允许执行和每个 t，`B(t)≤C_cut·t`，其中 B 是同一计费规则下接收侧在该窗口收到的信息 bit 数。所谓平均带宽、长期峰值标称值或单链路带宽并不自动证明这个任意前缀容量；必须包含多链路、控制、并行、时钟及其他可编码旁路。如果允许初始 burst `b`，只可据 `B(t)≤b+C_cut·t` 得出该最坏输入 `T≥max(0,(N−b)/C_cut)`。

这样得到的是：**对于每个全域正确且满足条件的协议，存在某个输入，其 z 完成时延不小于 N/C_cut**。不同 y 的完成时刻允许不同；不能从这点推出 169 某次输入、平均 TTFT、TPOT 或长时间稳态吞吐上限。额外独立工作可以并行隐藏该通信；若并行推理共同使用 cut，则资源竞争和窗口合并需要另证，不能把时间逐项相加。

## 4. 尚需针对 169 证明的前提

实际命中该 `muls_add_triton` 分支；两个输入可达的联合值域；需观察的最终结果及后继敏感性；数据在选定时窗起点的真实放置、副本及预计算；跨 cut 全信道和严格累计速率。任一项缺失时，只能把命题保留为条件例子，实际 169 的正通信量与可见延迟下界均为 UNKNOWN。

本审查只分析文本与数学条件，没有测量、执行模型、修改目标源码或变更任务状态。
