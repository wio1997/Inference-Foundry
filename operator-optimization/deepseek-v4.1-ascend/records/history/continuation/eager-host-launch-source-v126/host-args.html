Function

Configures the compute task of an operator and starts the task. This is an asynchronous API.

Prototype

1
 
aclError aclrtLaunchKernelWithHostArgs(aclrtFuncHandle funcHandle, uint32_t numBlocks, aclrtStream stream, aclrtLaunchKernelCfg *cfg, void *hostArgs, size_t argsSize, aclrtPlaceHolderInfo *placeHolderArray, size_t placeHolderNum)

Parameters

Parameter

Input/Output

Description

funcHandle

Input

Kernel function handle. For details about the type definition, see aclrtFuncHandle.

numBlocks

Input

Number of cores on which the kernel function will be executed.

stream

Input

Stream for executing the task. For details about the type definition, see aclrtStream.

cfg

Input

Task configuration. For details about the type definition, see aclrtLaunchKernelCfg.

If no configuration is specified, NULL can be passed.

hostArgs

Input

Pointer to the host memory address that stores all input parameters of the kernel function.

argsSize

Input

Size of parameter values in hostArgs, in bytes.

placeHolderArray

Input

placeholder parameter array.

aclrtPlaceHolderInfo is defined as follows:

typedef struct {
    uint32_t addrOffset;
    uint32_t dataOffset;
} aclrtPlaceHolderInfo;

The member variables are described as follows:

  • addrOffset: After the data area pointed to by placeholder is copied to the device, the actual device memory address needs to be updated to hostArgs during launch. This parameter specifies the location offset to be updated.
  • dataOffset: The data area pointed to by placeholder needs to be copied to the device. This parameter specifies the address offset of the data area based on hostArgs.

placeHolderNum

Input

Size of the placeholder parameter array.

Returns

0 on success; otherwise, failure. For details, see aclError.
