HF32

特性说明：

HF32的核心功能体现为：用户在输入矩阵A、B矩阵都为fp32数据类型的场景下，当配置开启HF32开关后，fp32数据在执行矩阵乘法运算前会被转换并舍入为HF32（half-fp32）格式。这种做法可使Mmad类（f322f32）接口的计算性能得到提升，但会带来一定的精度损失。需要注意的是，尽管中间计算使用HF32格式，最终的运算结果仍以fp32格式输出，以保证后续处理的兼容性。

开启HF32对性能的影响如下：

  • 针对如下产品型号：

    Atlas A3系列产品

    Atlas A2系列产品

    开启HF32可使Mmad类（f322f32）接口的计算性能提升至原来的两倍。

  • 针对Ascend 950PR&950DT系列产品，开启HF32可使Mmad（f322f32）接口的计算性能提升至原来的八倍。

舍入模式说明：fp32至HF32转换过程中的舍入模式由asc_set_hf32_round_mode接口配置。当HF32模式开启且设置asc_hf32_round_mode为NEAREST_AWAY时，FP32将以向最接近的值舍入，平局时远离零的方式舍入为HF32；若设置asc_hf32_round_mode为NEAREST_EVEN时，FP32将以向最接近的值舍入，平局时向偶数舍入的方式舍入为HF32。

图1 HF32数值精度示意图

注意，针对Ascend 950PR&950DT系列产品，其HF32格式的尾数位为10位，示意图如图2所示：

图2 Ascend 950PR&950DT系列产品HF32数值精度示意图

使用asc_enable_hf32开启HF32模式，使用asc_disable_hf32关闭；计算接口及输入类型要求参见asc_mmad。

使用示例：

C++
// 开启HF32模式
asc_enable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
asc_mmad(c, a, b, m, k, n, asc_unit_flag_mode::DISABLE,
         false, false, true);
// 关闭HF32模式并恢复舍入模式默认值
asc_disable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_EVEN);
