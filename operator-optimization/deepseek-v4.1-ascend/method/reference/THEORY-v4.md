# 理想 model 与不可超越吞吐上界 — PEAK-CEILING-v4

本文保留为理论分析参考；v2 的当前任务顺序和验收以 ../PROTOCOL.md 为准，止于融合机会发现与模块原因定位。

## 所求命题

固定硬件 H、模型及数值语义 M、负载 W、允许实现域 D、有效完成量 Q>0 和计时范围。真实实现集合为 P；每个实现时间为 T(p)。

    对所有 p∈P：T(p) ≥ L > 0
    因而吞吐(p)=Q/T(p) ≤ U=Q/L

只需证明时间下界，便有吞吐上界。不要求存在时间为 L 的实现，也不要求先找到时间上界或可达吞吐下界。“最优性能”可指未知的 supremum；U≥sup_p Q/T(p) 即够，不必相等。

对于稳态吞吐直接使用长期必要工作/时间的守恒界；Q 变化、排队、随机接受率和分位数指标不得不加条件地套用一次有限 Q/T。

## 松弛的正确方向

建立理想模型 R。若每个真实合法实现都能映射成 R 中成本不更高的候选，则：

    inf_{r∈R} cost(r) ≤ inf_{p∈P} T(p)

因此任何已证 L≤inf_R cost，也满足 L≤T(p)，可以安全取 U=Q/L。无需反向证明 R 的候选能在真实硬件执行；它允许过度理想甚至物理不可实现。

移除约束、扩大可行集合、降低非负成本，都可能构成安全松弛；每项需要说明没有反而限制真实实现。不能从“某个理想计划花 L”推出所有真实实现时间≥L，因为可能还有更快的理想计划。

若约束集合 K0⊆K1⊆…，每个新增约束对全部 P 必要，则各松弛最优时间不减、吞吐上界不增。无需解出这些最优时间：可直接给解析下界 l_k，并令：

    L[k]=max(L[k-1], l_k)
    U[k]=Q/L[k]

这保证同域有效且单调。若联合约束可推更强下界，提供新推导/证书。各界最大值仍不意味着真实可达或所有必要约束已穷尽。

## 理想基线

可以置零 CPU/Python/HTTP/分配/提交/回读/同步、kernel 边界和中间物化代价；允许最优融合、布局、理想分块、完美负载均衡、无限缓冲和最佳复用。可进一步放宽计算资源耦合、通信、存储和因果限制。明确写为松弛，不声称事实开销为零。

基线必要工作 W_min 与容量上限 C_max 必须有域内依据：

    L0=max_r W_min[r]/C_max[r] ≤ T(p)

这是必要工作与有效容量上限所给的解析下界，不是任意选择的理想计划耗时。

基本操作效率需区分吞吐、依赖延迟和资源占用。不同资源可重叠，不应无证据串行相加。乘加融合、指数实现、重排、数值容差和算法可能改变工作量；当前指令计数未证明必要时只能形成受限域/条件界。

直接放宽到零工作虽然可能有效，却只给平凡 L=0、没有有限 U。未知参数保留符号；未经证明的具体工作量/峰值不能支撑严格物理上界。当前算法复杂度不能自动约束所有可能算法。

## 如何加入必要约束

必要计算：对全部声明实现证明至少需多少工作，按适用资源容量上限推导；同一资源累计，耦合使用可证明的容量包络。

必要 I/O：证明数据不能来自允许的初态、缓存、复用或重算，确须跨某层/割搬运的最小信息量。给出必要字节和相应链路/存储容量上限；不得把某布局的全部通信直接推广到允许重分片的域。

有限存储：容量可以迫使额外 I/O 或重算，应联合考虑二者取舍；不能先选一种实现，再把它的搬运次数宣布必需。无限缓冲基线可在有证明后用真实容量收紧。

因果：对真正不可绕过的依赖路径，使用最短必要延迟而非当前算子耗时。块级数据可发布时，不能强制等待整个算子；也可以在更乐观层移除部分真依赖以取得较松界。

循环：在具有已证循环依赖/资源模型的域中，II≥max(ResMII,RecMII) 是必要界；不能因一般自回归存在就认定每个接受 token 一次完整串行前向。投机验证、接受/拒绝和计数必须纳入声明域。

任意相加需要证明费用位于同一不可重叠的必要路径；max 则常用于合并独立的全程时间下界。有限填管/排空若并非所有允许粒度都必需，不加进通用界。

## tile 例子的正确解释

固定 N 个不可分 tile，各搬入 r、计算 c、搬出 w；三阶段独立且 c≥r,w 时，r+Nc+w 可以是该特定流水模型的最短时间。但是，若声明域允许更细粒度流水，r 与 w 可能进一步缩短或隐藏，此固定 tile 最优不再自动约束更宽域。

通用乐观界可以先只取不可避免的总计算时间，再用经证明的总 I/O/资源/因果界收紧。不要求展示通信怎样隐藏，也不需达到该界。

## 求解器与数值的方向

最小化松弛时间时：
- 已证最优值或有效 lower/dual bound 可用于 L。
- primal/feasible/incumbent 的计划时间通常是松弛最优的上界，不能用于声称真实时间下界。
- 超时保留仍有效的 lower bound，不把最好候选当已证最优。
- 理想模型不可行需审查是否错误排除了真实执行；不能因为没有找到排程就宣称物理不可行。
- 任意程序输出需审核约束与成本映射；重复一致不替代数学证明。

L 的数值舍入不能向上扩大，U 的保守数值应向上取包络；容差必须带方向。浮点解不能不经检验当严格证书，可用有向误差、区间或有理数等方法。

## 不确定性与证据等级

设参数 θ 属于有依据的集合 Θ。若每个 θ 都有有效时间下界 l(θ)，且真实 θ∈Θ：

    L_robust=inf_{θ∈Θ} l(θ)
    则对真实实现 T≥L_robust，U_robust=Q/L_robust

保留相关性；为乐观包络放宽相关性可以让界更松，不能未经证明反向收紧。条件区间、统计置信区间和有保证的参数集合分别标记。任何假设参数只支持显式条件上界。

DOCUMENTED 是资料声称，仍需审查严格方向；MEASURED 是观测，不是严格容量极限；DERIVED 必须列前提；ASSUMED 支持条件结论；UNKNOWN 保留符号。

标签：REVIEWED_CEILING_IN_STATED_DOMAIN 表示在列明且有依据的前提/域内完成复核；CONDITIONAL_CEILING 表示依赖未证实假设；SYMBOLIC_CEILING 表示尚无完整数值；INCOMPLETE 表示必要证明或有限界未建立。标签不是无条件物理真理。

## 可复现与证明强度

冻结来源快照、命题、允许域、松弛清单、每条必要约束、推导、输入/脚本/设置/SHA 和原始输出。分别审核事实适用性、模型覆盖/必要性、算术/求解正确性。

可审查数学推导、独立计算证书、形式化证明应分别标识；没有形式化工具验证不称机器形式化证明。哈希一致不证明物理模型正确。

本任务没有必须的可达方案、开发优化、真实 TPS 提升或上下界 gap。理论上界与已存在同口径实测可作附带对照，但“未达界”不是本任务失败，比例也不是已证可达提升空间。
