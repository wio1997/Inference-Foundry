# 32K首次正式冷热观测

## 原理与代码

候选仅把mHC中的20轮FP32 Sinkhorn归一化融合；保留迭代次数、epsilon位置及投影/残差计算。源码见[融合点](../records/points/GLM-OPT-0002/point.md)。组件、图回放和七个P/D诊断已通过；真实模型新融合核的profile命中与时间归因仍需补齐。

## 波动噪声

最后两轮预热时长、TTFT、TPOT相差1.10%、0.24%、2.08%。这些是预热稳定证据，不能替代正式同臂A-A噪声标定。每个配置目前只有一次冷测和一次热重放；两者缓存条件不同，不能把冷热差当独立重复。

## 结论与边界

32K观测指标改善成立，独立融合贡献和可重复收益仍未严格分离。旧基线与候选的启动、编译历史不同，原生自动KV容量每角色有128token差异；相同CLI不等于所有有效工作都已控制。热重放也不等于100%缓存命中。

当前vLLM G3的32K原冷/热输出为210.1083/209.3023 token/s，仍高于当前SG；其最终充分预热同协议复测尚未完成。SG其余64K/128K/256K、完整新profile及最终对比地图均未完成，不能据此提升全任务Current或宣布性能已对齐。
